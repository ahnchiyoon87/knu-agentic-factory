# 제작 — 특강을 만드는 전부. 강의할 때는 안 봐도 됩니다

자료를 **만들거나 고칠 때만** 여는 곳입니다. 특강을 **하는** 데 쓰는 것은 `특강/` 에 있습니다.

| | 무엇 |
|---|---|
| `덱빌드/` | 슬라이드를 만드는 스크립트 + 원고 · 설명란 |
| `기준판/` | 슬라이드 디자인 규격 원본 |
| `참고자료/` | 교안 · 리서치 · 견적확정서 · 설명대본 · 앞 세션 실라버스 |
| `강의안원본/` | 대외 강의안(docx)의 원본 마크다운. **여기를 고치고 다시 뽑는다** |
| `기록/` | 검증 기록 |
| `검증도구/` | `리허설.py`(75항목) · `배포본만들기.py`(26항목) · 센서데이터(생성기·검증기·데이터) |
| `빌드도구/` | `pptx만들기.py` · `드라이브폴더만들기.py` · `공유본만들기.py` · `md2pdf.py` |
| `산출물/` | 스크립트가 뽑은 것 (통째로 gitignore — 지워도 됩니다) |

## 슬라이드를 고치는 법

**PNG 를 직접 고치지 마세요.** 빌드 스크립트가 원본입니다.

```bash
cd 덱빌드
python build_1일차.py        # 덱 HTML
python emit_docs.py          # 원고·설명란 (같은 데이터에서 — 어긋날 수 없음)
python render.py 1일차덱      # PNG → ../../특강/당일/슬라이드/1일차/ 로 떨어짐
```

## 강의안(docx)을 고치는 법

`강의안원본/` 의 마크다운을 고치고 다시 뽑습니다. **docx 를 손으로 고치면 다음에 어긋납니다.**

원본은 **2일차·3일차** 표기입니다 — 대외 문서라 전체 4일 과정 기준입니다.
저장소 안쪽(폴더·코드·진행표)은 1일차·2일차이니 헷갈리지 마세요.

**모든 서술은 슬라이드 원고(`덱빌드/build_*.py`)에 대응해야 합니다.**
기억으로 쓰면 틀립니다 — 실제로 「에이전트는 넷」을 원고와 다르게 썼다가 잡은 적이 있습니다.
