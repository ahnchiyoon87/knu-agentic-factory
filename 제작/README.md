# 제작 — 강의할 때는 안 봐도 됩니다

자료를 **고칠 때만** 여는 곳입니다.

| | 무엇 |
|---|---|
| `덱빌드/` | 슬라이드를 만드는 스크립트 + 원고 · 설명란 |
| `기준판/` | 슬라이드 디자인 규격 원본 |
| `참고자료/` | 교안 · 리서치 · 견적확정서 · 전수조사 기록 |
| `기록/` | 검증 기록 |

## 슬라이드를 고치는 법

**PNG 를 직접 고치지 마세요.** 빌드 스크립트가 원본입니다.

```bash
cd 덱빌드
python build_1일차.py        # 덱 HTML
python emit_docs.py          # 원고·설명란 (같은 데이터에서 — 어긋날 수 없음)
python render.py 1일차덱      # PNG → ../../1일차/강의자료/ 로 떨어짐
```
