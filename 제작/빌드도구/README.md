# 빌드도구 — 밖으로 나갈 것을 뽑는 곳

| 무엇 | 하는 일 |
|---|---|
| **`pptx만들기.py`** | 슬라이드 PNG 를 pptx 로 묶어 `특강/당일/` 에 떨어뜨린다 |
| **`드라이브폴더만들기.py`** | 구글드라이브에 올릴 폴더(실습 ZIP 포함)를 `제작/산출물/드라이브업로드/` 에 만든다 |
| **`공유본만들기.py`** | 대표님(1일차 담당)께 보낼 실라버스 PDF+docx 를 `제작/산출물/공유/` 에 만든다 |
| `md2pdf.py` | `.md` → PDF (playwright · 맑은 고딕). 위 도구들이 부른다 |

```bash
cd 제작/빌드도구
python pptx만들기.py && python 드라이브폴더만들기.py && python 공유본만들기.py
```

드라이브폴더만들기는 **배포본이 먼저 있어야** 합니다 — `python 제작/검증도구/배포본만들기.py --검증`.
