# K-정밀 7일치 센서 데이터셋

경남대 RISE 피지컬AI 사관학교 8월 특강
**1일차 실습 실습의 재료**다. 학생 저장소에는 `데이터/` 로 들어간다.

```bash
python -m pip install "numpy" "pandas>=2.2,<3"
python generate.py     # 데이터 생성 (시드 42 고정)
python verify.py       # 데이터가 1일차 학습을 성립시키는지 검증
```

> `pandas 3.x` 는 이 환경에서 DLL 로드가 시스템 정책에 막혀 **2.2.x 로 고정**했습니다.

## 물리 파라미터를 여기에 적지 않은 이유

`generate.py` 는 시뮬레이터의 `config/sim_profile.json` · `layout.json` 을 **읽어서** 씁니다.
온도 모델·노이즈·드리프트 기울기를 두 벌로 두면 반드시 어긋나고, 어긋나면
*"과거 + 현재가 한 테이블에 합쳐진다"* 가 성립하지 않습니다.

시뮬레이터 폴더가 없으면 생성이 **중단**됩니다(조용히 다른 값을 쓰지 않습니다).
경로는 `--sim-config` 로 바꿀 수 있습니다.

설비별 정상 온도도 물리식 `24 + 16.7 × (rpm/1000)^1.4` 에서 그대로 나옵니다.

|---|---|---|---|---|---|---|
| 정상 온도 | 62.0 | 68.0 | 62.0 | 56.2 | 74.3 | 65.0 ℃ |

## 이 데이터가 1일차 학습을 성립시키는가 — `verify.py` 실측

학생이 1일차에 짤 **이동 윈도 z-score(윈도 60분)** 를 그대로 돌린 결과입니다.

| 리서치 가설 | 실측 |
|---|---|
| **(a) 드리프트는 이동평균이 적응해 미탐** | 드리프트 구간 평균 \|z\| **0.94** vs 정상 구간 **0.81** — 구별되지 않음 |
| **(b) 스파이크는 z-score로 정탐** | 3회 모두 \|z\| = **6.7 / 6.5 / 6.7**, 정상 구간 최댓값 4.40 — 확실히 분리 |
| **(b′) 임계를 낮추면 오탐 급증** | k=3 오탐 **263행** → k=2 **5,245행** (**19.9배**) |
| **(c) 결측은 통계를 깨뜨린다** | 결측 종료 후 60분 중 **58행이 NaN** — 결측 처리 TODO가 필요해짐 |

고정 임계값의 한계(1일차 서사)도 데이터에서 성립합니다.

- 7일 내내 온도가 **80℃를 넘은 적이 한 번도 없음** (0행)
- 드리프트 구간 최고 온도도 **63.87℃**
- 진동 스파이크도 고정 임계 8.0mm/s를 **못 넘음** (최고 4.28mm/s)
- 임계를 66℃로 낮추면 → **21,389행 · 설비 3대**가 하루 종일 울림

마지막 줄이 슬라이드의 *"선을 66도로 낮추면 여름철 낮에 정상적으로 돌던 다른 설비들이 하루 종일 경고음을 울린다"* 를 데이터로 뒷받침합니다.

## 교안에 없어 별도로 정한 것 (2건)

교안이 정하지 않은 항목만 근거를 달아 확정했습니다.

### 1. 일주기 외기 변동 — 채택

`amplitude_c: 1.0`, 오후 3시 최고. **7일치 데이터에 일주기가 없으면 비현실적**이고, 무엇보다 드리프트가 너무 쉽게 눈에 띕니다. 낮에 온도가 오르는 성질이 위의 "66℃로 낮추면 오탐" 문장을 데이터로 성립시킵니다. `--no-diurnal` 로 끌 수 있습니다.

### 2. 설비 정지 구간 — 비채택 (기본 0)

처음에는 공구 교체·점검 정지를 넣었습니다. **실측 결과 정지/재가동 전이가 z-score에 \|z\|=7 수준의 아티팩트를 만들어, 심어 둔 진동 스파이크(\|z\|~4)를 덮어버렸습니다.**

1일차 TODO는 3개(윈도 통계 / 임계 판정 / 결측 처리)뿐이고 `run_state` 필터가 없으므로, 설계된 난이도를 넘는 요소입니다. 그래서 **기본값 0**으로 껐습니다.

`config.json` 의 `stops.per_machine_per_day` 를 올리면 되살아나지만, 그때는 정탐·오탐 수치를 다시 확인해야 합니다.

> 진동 스파이크 크기를 라이브 프리셋의 6σ가 아니라 **15σ**로 둔 것도 같은 이유입니다.
> 10,080 샘플에서 6σ(+0.72mm/s)는 노이즈 최댓값(\|z\|≈3.9)과 구분되지 않았습니다.
> 15σ(+1.8mm/s)는 고정 임계 8.0mm/s를 여전히 못 넘으면서 z-score로는 확실히 잡힙니다.
> 스파이크 간격도 7분 → **90분**으로 넓혔습니다. 이동 윈도(60분)보다 짧으면
> 세 개가 같은 윈도에 들어가 서로의 표준편차를 부풀려 자기들끼리 가립니다.
