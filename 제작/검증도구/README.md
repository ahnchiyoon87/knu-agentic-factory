# 검증도구 — 수업이 그대로 돌아가는지 기계로 확인하는 곳

| 무엇 | 하는 일 |
|---|---|
| **`리허설.py`** | 이틀을 사람 없이 재생 — **75항목 · 약 11분** (`--부하` 는 39명 동시 진단을 실제 모델로 부름 · 비용) |
| **`배포본만들기.py`** | 학생 저장소를 `제작/산출물/배포본/` 에 뽑는다. `--검증` 이 학생 조건(cp949)으로 **26항목** 확인 |
| `센서데이터/` | 7일치 CSV 생성기(`generate.py`) · 검증기(`verify.py`) · 데이터 |

```bash
cd 제작/검증도구
python 배포본만들기.py --검증                      # 26항목
python 리허설.py --token <시뮬레이터 .env 의 INSTRUCTOR_TOKEN> --부하   # 75항목 · 약 11분
```

서버(`특강/시뮬레이터`)가 떠 있어야 리허설이 돕니다.
**리허설·검증이 도는 동안 `특강/학생배포/` 를 편집하지 마세요** — 도중 편집으로 깨진 적이 있습니다.
