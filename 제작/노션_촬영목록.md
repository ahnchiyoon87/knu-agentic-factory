# 노션 1교시 — 찍을 화면 목록

학생과 같은 조건(**빈 노션**)에서 처음부터 만들면서, 아래 순간에 **화면 전체**를 찍습니다.
파일 이름은 신경 쓰지 않아도 됩니다 — **찍은 순서만** 지켜 주세요.
(`D:\사진\Screenshots` 에 그대로 쌓아 두시면 됩니다.)

> 지금 슬라이드가 쓰는 화면은 예전에 **도형으로 그린 재현본**이라 실제 노션과 다릅니다.
> 속성 메뉴만 해도 이름 칸 위치 · 두 줄 배열 · 「날짜」 항목이 전부 달랐습니다.
> 한 장씩 땜질하면 계속 어긋나므로 **처음부터 실제 화면으로 다시 만듭니다.**
