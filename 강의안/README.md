## 지켜야 할 것

**일차 표기는 1일차·2일차입니다.** 전체 4일 과정 중 우리가 맡은 이틀이고,
저장소·코드·진행표가 전부 그 기준입니다. 다른 이름을 쓰지 않습니다.

**여기 들어가면 안 되는 것** — 팀·발표 규칙, 이탈 방지 장치, 검증 현황, 강사 지시 같은
**운영 얘기.** 이 문서는 「무엇을 배우고 무엇을 만드는가」만 담습니다.

**모든 서술은 슬라이드 원고에 대응해야 합니다.** 기억으로 쓰면 틀립니다 —
실제로 「에이전트는 넷」을 원고와 다르게 썼다가 잡은 적이 있습니다.
원고는 `제작/덱빌드/build_1일차.py` · `build_2일차.py` 입니다.
