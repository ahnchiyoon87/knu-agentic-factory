**Day 4 실주행 추기:**

- **1차 실주행** — 주입→감지(9회차, +0.4℃)→진단(openai: 냉각 계통 보류가 원인, WO-2026-0801 인용)→감속 자동 실행(1792→1434rpm)까지 문서 그대로 ✅. 그러나 **심각도 LOW 판정 → 파견 요청 없음 → 가이드의 5~7단계(승인·AMR)가 발생하지 않음** ❌
- **원인** — 파견 여부가 LLM 재량이라 비결정적. 교안 294행 시연 각본은 "감속 실행 + 정비 로봇 파견 승인 요청"을 요구함
- **조치** — 정답 프롬프트에 파견 규칙 추가: "원인이 정비 보류·지연이면 감속과 함께 dispatch_robot 요청까지 낼 것 (파견은 사람 승인을 거치므로 요청을 망설이지 말 것)" — HITL 설계 취지와 일치
- **2차 실주행 (규칙 추가 후)** — **7단계 완주 ✅**: 주입 → 감지(+0.4℃) → 진단(MEDIUM, WO-2026-0801 인용, 파견 이유 명시) → 감속 자동(1432→1145rpm) → **승인 요청 프롬프트(가이드에 적은 문구와 실물 일치: "승인 요청 — 되돌릴 수 없는 행동입니다 … [y/N]")** → y 승인 → **dispatch_robot(AMR-01→EQ-03) 실행** → AMR 이동 완료(복귀 IDLE) → 온도 52.9→44.4℃ 실측 하강
- **회귀 검증** — 정답 프롬프트 수정 후 W6 `verify_lab.py` 재실행: **전 항목 통과** (감지 9항목·진단 지시문 8항목)
- **가이드 반영** — Day 4 §2-2 diagnoser 힌트에 파견 규칙 추가 (학생 구현도 같은 함정을 피하도록)
