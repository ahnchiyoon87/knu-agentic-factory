## 고장 주입 — 39명 동시 (§1)

`제어개방.py --inject` 는 **한 번에 한 명**만 됩니다. 39명은 반복해서 넣습니다.

```bash
# Git Bash / macOS / Linux
for i in $(seq -w 1 39); do python tools/제어개방.py --inject S$i; done

# Windows PowerShell
1..39 | % { python tools/제어개방.py --inject ("S{0:d2}" -f $_) }
```

- 한 명당 1초 남짓, 전체 40초쯤 걸립니다. **학생에게 "지금 넣습니다" 라고 말한 뒤** 돌리세요.
- 되돌리려면 `python tools/제어개방.py --end` (주입 중단 + 제어 잠금 + 배속 60).

> ⚠️ 이 반복 명령은 도구에 없는 조작입니다. `--inject-all` 옵션을 추가해 두면
> 당일 실수가 줄어듭니다. **D-7 리허설 전에 넣을 것을 권합니다.**

## 제어 개방 — 덱 「지금 제어 권한이 열렸습니다」 슬라이드에서

```bash
python tools/제어개방.py
```

- 제어 API 개방(`tenant_id="*"` — **개인 공장까지 전부**) + 배속 x120 + 팀 키 출력.
- 팀 키 출력은 오늘 안 씁니다. 무시하세요.
- 이걸 안 누르면 학생 `loop.py` 가 전부 **403** 으로 죽습니다.

> 슬라이드를 넘기면서 실제로 누르는 것이 가장 좋습니다. "지금 열렸습니다" 가 사실이 됩니다.

## 폐루프 주입 — 39명 동시 (§2-3)

전원이 `python loop.py` 를 돌린 것을 확인한 뒤:

```bash
for i in $(seq -w 1 39); do python tools/제어개방.py --inject S$i; done
```

- 배속 x120 기준 **감지까지 약 100초**. x60 이면 약 190초.
- 그 사이 터미널이 조용한 것이 정상이라고 **미리** 말해 두세요. 안 그러면 39명이 동시에 손을 듭니다.

## 못 끝낸 학생 (§2)

- 시간이 15분 남았는데 못 돌린 학생에게 **「동작 보장 최소 경로」 카드**를 줍니다.
  (`산출물/공통/인쇄카드/카드_인쇄용.html`)
- 1일차에 만든 `detect.py` 를 못 끝낸 학생은 **2일차 시작 전에** 정답본을 줍니다.
  그러지 않으면 오늘이 통째로 막힙니다.
