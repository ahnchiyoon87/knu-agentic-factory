> 구조: 교안 검토 → 틀 수립 → 제작 → 추인 요청 → 일정

## ① 먼저 교안부터 봤습니다 (30초 + 대조표 짚기)

제작에 들어가기 전에 **교안 9페이지를 전수 검토**했습니다. 견적확정서, 호서대 기존 자료 240장도 전부 대조했습니다.

그 과정에서 갈라낸 것이 있습니다 — **교안이 정해 둔 것과, 정하지 않은 것.**

### 교안이 Day 1에 정해 둔 것 (원문 기준)

**제목** — 「보기: 코드를 짜는 시대에서, 시스템을 말하는 시대로」

**학습목표 4개** — 오늘 끝나면 학생이 할 수 있어야 하는 것:
1. 피지컬 AI를 **인지→판단→행동의 폐루프**로 정의하고, 에이전틱 AI가 그중 '판단·행동'을 맡는 구조임을 설명
2. **에이전틱 디자인 패턴 5가지**의 이름과 쓰임새 구분
3. 코드를 치지 않고 **프롬프트만으로** 시뮬레이터와 연결된 실시간 관제 대시보드 제작
4. 프롬프트만으로 개발할 때의 한계(컨텍스트 붕괴)를 **직접 겪어서** 앎 ← Day 2의 동기

**시간표** — 00:00 오리엔테이션(15분) → 00:15 강의 1(55분) → 01:10 셋업 랩(30분) → 휴식 → 01:50 Lab 1-1(110분) → 03:40 랩업(20분)

**강의 1 목차 (약 24장)** — 아래 여섯 블록. **순서·내용 변경 불가**가 견적 조건.

### 교안 목차 ↔ 우리 슬라이드 대조표 ★ 회의에서 짚을 표

| 교안 원문 (요지) | 교안 장 | 우리 장 |
|---|---|---|
| **피지컬 AI란 무엇인가** — 센서로 인지, AI가 판단, 액추에이터로 행동하는 폐루프. 자율주행·휴머노이드·스마트팩토리 전부 이 구조 | 1–4장 | **1~13장** (새벽 3시 사건으로 도입 → 폐루프 → 피지컬 AI 정의 → 에어컨 비유) |
| **왜 하필 지금인가** — LLM이 '판단'을 어디든 붙일 수 있는 범용 엔진이 되며 병목이 풀림 + 채용시장·참여기업 인재상 | 5–7장 | **14~19장** (50년 반전 → 병목=판단 칸 → LLM → 인재상 → 4일 지도) |
| **에이전트란 무엇인가** — 뇌+도구+루프+자율성. 챗봇·코파일럿과 구분 | 8–10장 | **20~24장** (환각 → 눈·손 없음 → 에이전트 → 비교표 → ReAct) |
| **디자인 패턴 5종** — Chaining·Routing·Parallelization·Orchestrator-Worker·Evaluator-Optimizer. **각 패턴을 전부 공장 사례로** | 11–17장 | **25~31장** (다섯 패턴 전부 K-정밀 사례, 물류 예시 0건) |
| **오늘의 무대** — K-정밀 시뮬레이터 강사 시연. "4일 뒤 여러분의 에이전트가 이 공장을 움직입니다" | 18–20장 | **32~34장** (33장에 실제 시뮬레이터 캡처) |
| **실습 예고** — "오늘은 보는 눈을 만듭니다. 코드 한 줄 안 치고" | 21–24장 | **35~38장** (바이브코딩 → 실습 4단계 → 셋업 → 마무리) |

→ **여섯 블록의 순서·내용이 그대로고, 각 블록을 더 잘게 쪼갰을 뿐입니다.** 이것이 "24→38장"의 실체입니다.

**왜 쪼갰나** — 24장이면 한 장을 평균 2.3분 띄워 둬야 합니다. 그러면 **화면은 멈춰 있는데 말은 계속 앞으로 갑니다.**
강사가 둘째·셋째 이야기로 넘어가도 학생 눈앞엔 첫째 이야기 화면이 그대로라, **지금 말하는 대목을 화면에서 찾을 수 없고**
화면과 말이 어긋나는 순간 집중이 끊깁니다. 그래서 내용을 더한 게 아니라 **말이 바뀌면 화면도 바뀌게** 장면 단위로 쪼갰습니다.
한 장 한 장면, 장당 1.45분 — 장수는 늘었지만 학생이 소화하는 내용량은 교안 그대로입니다.

- **교안이 정하지 않은 것** — 슬라이드의 흐름(각 블록 안을 어떻게 풀지), 디자인, 한 장에 담는 양.
  → **저희가 틀을 세웠습니다.**

## ② 그래서 틀을 먼저 세웠습니다 (1분)

틀은 셋입니다.

**1) 이야기 틀** — 교안 목적이 지식 전달량이 아니라 임팩트라서, 개념 나열 대신 **사건 하나**로 끌고 갑니다.

| 단계 | 장면 |
|---|---|
| 페인포인트 | **새벽 3시**, K-정밀 CNC 한 대가 시간당 0.5℃씩 조용히 오르다 하루치 생산분 전량 폐기 |
| 희망 | "임계값 알람 걸면 되잖아" (80℃) |
| **반전 ①** | **80도를 한 번도 안 넘었다** → 값이 아니라 "값이 걸어온 길" |
| 해소 | 인지→판단→행동→다시 인지 = **폐루프** = 피지컬 AI (에어컨/전자레인지) |
| **반전 ②** | **이 고리는 50년 전에도 있었다** — 왜 아직도 못 잡았나 |
| 아하 | 병목은 「판단」 칸. 세 번째 재료 **LLM** = "왜 하필 지금인가"의 답 |
| 동기 | MES·PLC를 잇는 인재상 · 참여기업 15개사 · 채용약정 4개사 |
| 다리 | 4일 지도 + "그 판단을 LLM에게 그냥 물어보면 될까요?" → 후반부가 답 |

**새벽 3시 사건 하나가 4일을 관통합니다.** Day 3 실습 데이터에도, Day 4 라이브 시연에도 같은 사건이 같은 수치로 심어져 있습니다.

**2) 디자인 틀** — 기준판 8종을 만들어 모든 장이 그 중 한 형식을 따릅니다.
색 4가지(남색·보조남색·주황·회색), 글자 크기 위계 고정, 배경은 순백 하나(표지만 남색). 55장이 한 벌로 보입니다.

**3) 수치 정합 틀** — 슬라이드의 숫자는 전부 무대 설정 문서에서만 나옵니다.
62→64℃ · 0.5℃/h · 80℃ — **슬라이드·시뮬레이터(W1)·데이터셋(W5) 세 곳이 같은 숫자**를 씁니다.

## ③ 그 틀로 Day 1을 만들었습니다 (30초)

**오리엔테이션 17장 + 강의 1의 38장 = 55장.**
강의 1은 PPTX 완성본이 나왔습니다 (`산출물/W2_강의슬라이드/Day1_강의1_38장.pptx`).

제작 방식 — 삽화는 생성 도구로 여러 판을 뽑아 **장별로 가장 좋은 것을 선정**,
글자는 생성물을 쓰지 않고 **확정 원고에서 직접 조립**. 그래서 틀(크기·색·여백·배경)이 100% 지켜지고,
생성 도구가 지어낸 숫자가 화면에 들어올 길이 없습니다. 33장에는 실제 시뮬레이터 캡처가 들어갑니다.

## ④ 교안과 달라진 것 — 추인 요청 (1분)

**추인 4건 (이미 반영, 사후 승인)**

| # | 항목 | 사유 |
|---|---|---|
| 1 | 장수 24 → **38장** (견적 상한 36장 +2) | 장당 2.3분이면 화면은 멈춰 있는데 말은 앞으로 가서, 화면과 말이 어긋남. 말이 바뀌면 화면도 바뀌게 장면 단위로 쪼갬 — 장당 1.45분, 내용량은 교안 그대로 |
| 2 | **오리엔테이션 17장** 별도 제작 | 교안 시간표의 첫 15분이 산출물 목록에서 누락. 만드는 것이 교안 이행 |
| 3 | 호서대 **영상 재활용 미이행** | 전수조사 결과 영상 실물 없음 → 슬라이드로 대체 |
| 4 | **사실 조정 3건** | ① 30년→**50년**(PLC 1969) ② "경남 세계 최고 로봇 밀도"→근거 확인 불가라 "로봇도 센서도 이미 깔려 있다"로 ③ K-정밀 **야간 무인** 설정 명문화 |

**결정 요청 (Day 3 착수 전 필수)**

- **GraphRAG 축소** — 실습 환경에 그래프 DB 없음, 호서대 자료 전무.
  단순 RAG + Text2SQL 2종으로 축소 + 교안 학습목표 2번 문장 수정.

**이 자리에서 정해 주시면 좋은 것**

## 예상 질문 대비

**Q. 왜 생성 도구 출력을 그대로 안 썼나?**
검사해 보니 글자 크기 미준수, 없는 숫자 날조(72.5℃), 문장 중복이 실제로 나왔습니다.
삽화만 살리고 글자는 확정 원고로 직접 찍어 재발을 구조적으로 막았습니다.

**Q. 38장을 55분에 다 넘길 수 있나?**
장당 1.45분. 쪼갠 이유 자체가 "말과 화면을 맞추는 것"이라 한 장에 머무는 시간이 짧습니다.
오히려 24장일 때가 한 장에서 2.3분을 버텨야 해서 어렵습니다. 리허설에서 시간 검증 항목으로 잡아 뒀습니다.

**Q. 장수가 늘면 학생 부담도 늘지 않나?**
내용을 추가한 게 아니라 같은 내용을 장면 단위로 나눈 것입니다. 학생이 소화하는 총량은 교안의 여섯 블록 그대로이고,
오히려 한 화면에 담긴 글이 줄어 장당 부담은 내려갑니다.

**Q. 강사 대본은?**
슬라이드가 스스로 말하게 설계했습니다(그림 안 라벨). **별도 대본 제작 여부는 이 자리에서 결정 부탁드립니다.**

**Q. 다른 날도 이 방식인가?**
네. 틀(기준판·규격·검사 도구)이 갖춰져 있어 Day 2부터 속도가 붙습니다.

**Q. 왜 "경남 세계 최고 로봇 밀도"를 뺐나?**
제안 발표자료 원문인 것은 확인했으나 통계 근거를 검증할 수 없었습니다.
검증 가능한 문장으로 바꿔도 논지(병목은 통합 인력)는 그대로 섭니다.
