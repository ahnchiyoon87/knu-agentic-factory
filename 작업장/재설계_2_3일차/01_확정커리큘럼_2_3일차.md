## 1. 지켜야 하는 교안 규칙

### 「4비트 학습 루프」 — 모든 실습의 골격
```
작은 성공  →  의도된 불편  →  대조 해결  →  자산화
```
그리고 **어제 겪은 불편이 오늘 배울 것의 동기**가 되게 날짜끼리 이어 붙인다.

### 설계 원칙 5가지 (교안 p.1)
| # | 내용 |
|---|---|
| 1 | 소재는 끝까지 피지컬 AI. **폐루프(인지→판단→행동)**가 뼈대 |
| 2 | 매일 마지막은 **실제로 돌아가는 결과물** = "와" 순간 |
| 3 | 모든 실습을 4비트 루프로. 날짜끼리 이어 붙인다 |
| 4 | 실습 **60~70%**. 모든 실습 앞에 **"왜 하는가"** (← 가이드 문서 규정. 슬라이드 아님) |
| 5 | 핵심 로직은 라이브러리로 때우지 않고 **직접 짜게 한다** |

### 이야기 구조 (Day1에서 확립된 골격)
```
페인포인트 → 축적 → 희망 → 반전① → 해소 → 반전② → 원인 → 아하
          → 동기 → 넘기는 질문 → 답 → 확장 → 무대 → 닫기
```

### 절대 규칙
- **반전 유출 금지** — 어떤 이상이 잡히고 안 잡히는지 슬라이드에 한 글자도 쓰지 않는다.
  학생이 코드를 돌려 발견한다. `00_작업파일/검사_Day234.py` 가 자동 검사한다.
- **"그런데/하지만" 으로 시작하는 반전 문장 금지**
- **무대 고정** — 경남 창원 가상 정밀기계 제조사 「K-정밀」 · CNC 6대(EQ-01~06) · AMR 2대.
  여기 없는 사실·숫자를 지어내지 않는다.
- **대본 없음** — 슬라이드만 보고 뜻이 통해야 한다. 삽화 안 라벨이 대본 역할.
- **노션 AI 기능 미사용** — 전부 손으로

### 진행 방식 규칙 (2026-08-10 확정)
- **발표·시연·투표·팀 데모 전부 없음.** 39명 중 2명만 앞에 세우면 나머지는 구경꾼이 되고
  지목당할까 봐 긴장한다.
- 대신 **전원 동시 실행** — 강사가 앞에서 먼저 한 번 하고, "다 같이 엔터"로 39명이 동시에 돌린다.
  39개 화면에서 동시에 결과가 뜨는 것이 시연보다 강하다.
- 안 되는 사람은 **손만 들면 조교가 간다.** 앞에 나올 일 없다.
- 숙제 확인도 남의 노션을 띄우지 않는다. 강사 자기 것만 띄운다.
