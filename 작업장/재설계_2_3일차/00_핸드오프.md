## 3. 노션 실습 — 설계 논의 결론

### 원본 설계 (사용자 작품, `노션자산화/원본_진행문서.html`)
사용자가 이미 만들어 둔 **자산화 방법론 실습**. 매우 잘 설계돼 있고 뼈대는 유지한다.

흐름: 강의 듣고 남은 **물음표투성이 필기** → 그 물음표가 곧 **구멍 목록** →
개념 카드 DB로 → **자료 덮고** 내 문장으로 씀 → AI에게 물은 답은 **토글에 숨김** →
필터 뷰로 남은 것만 → 마지막에 AI에게 통째로 시켜보고 **"내가 30분, AI가 20초"** →
**"그런데 저건 아직 내 자산이 아니다"**

**핵심 장치 두 개** (이게 이 실습의 정체성. 절대 빼지 말 것):
1. **자료 덮고 쓰기** — 보고 쓰면 옮겨 적기, 덮고 써야 내 머리를 통과
2. **AI 답은 토글에 접어두기** — 붙여넣기가 아니라 문제집이 됨

단계: 00 내 상태 보기(2분) → 01 구멍 뽑기(5분) → 02 템플릿(6분) → 03 카드 하나 끝까지(10분)
→ 04 안 풀리는 건 접어둠(5분) → 05 남은 것 필터(4분) → **전환점("그런데")** → 06 AI에게 넘겨봄(6분)
→ 07 나누는 기준(3분). 합 41분.

템플릿 4구획: ① 🗣 자료 덮고 설명하면 ② ❓ 이게 없으면 뭐가 안 되나 ③ 💻 코드로는 ④ ▸ 자료 원문/내 필기(토글)
DB 속성 2개만: **이해도**(설명못함/대충앎/설명가능) · **자료**(PDF 쪽수)

### 현장용으로 바뀌어야 하는 것
원본은 **영상 촬영 전제**로 쓰였다. 현장은 39명이 동시에 같은 화면에 있어야 하므로:
- **기능을 따로 가르치지 않는다.** `/데이터베이스`는 카드 만들 때, 템플릿은 양식 만들 때,
  토글은 답 숨길 때 — **쓰는 순간에** 배운다. 앞에 몰아서 하면 "왜 배우지" 상태가 됨
- 단, **출발선 맞추기 10~15분**은 필요 (가입·페이지 생성에서 막히면 그 뒤가 다 무너짐)
- 단계마다 **"지금 화면이 이래야 합니다" 체크포인트**
- **학생용 시작 템플릿** — 복제 버튼 하나로 페이지 구조가 잡혀 있어야 함
- 뒤처짐 확인 신호(손 들기 등)와 조교 순회 지점

### 예시 재료를 무엇으로 할 것인가 — **결론: "오늘 배울 것"의 축소판**
검토한 안들:
- ❌ 지금 원본의 예시(Agentic AI 3회차 — 도구호출·ReAct) → 우리 3일차 내용이라 **2일차에 쓰면 스포일러**
- ❌ 각자 자기 필기 → 필기 상태가 제각각이라 현장에서 화면이 안 맞음
- ✅ **오늘 오후 실습의 핵심 개념 3~4개짜리 미니 강의자료 + 물음표 찍힌 예시 필기**

이유: 노션 실습이 **오후 실습의 예습**을 겸하게 된다. 학생 체감이 "노션 배우는 시간"이
아니라 "오후 준비하는 시간"이 되어 이탈이 없고, 오후에 그 개념이 실제로 나오면
**"아 아까 카드 만든 그거"**가 되며 자산화의 효용이 그 자리에서 증명된다.

**→ 만들어야 할 재료 2종 (아직 없음)**
1. 미니 강의자료 (1~2장) — 오후 실습 핵심 개념. 예: 이상 감지란·평균에서 벗어난 정도·임계값
2. 예시 필기 원본 (txt) — 물음표가 찍힌 날것. 예: *"z-score가 뭔데?"* *"임계값 왜 3?"* *"못 따라감"*

### 숙제
**"오늘 실습에서 제일 헷갈렸던 것 카드 2장."** 범위를 크게 잡으면 안 한다. 2장 = 30분.
다음 날 아침 3분에 두세 명 것을 화면에 띄운다(검사가 아니라 "이렇게들 하셨네요" 수준).
4일치가 쌓여 **마지막 날 노션 URL 제출 = 수료 조건**.

### 노션 vs GitHub 역할
**GitHub = 실물**(코드·데이터·결과물, 이미 준비 완료) / **노션 = 표지**(정리·회고·스크린샷 + 깃 링크).
"코드는 깃, 정리는 노션"으로 학생에게 명확히.

## 9. 놓치면 안 되는 것

- **원본 진행문서의 두 장치**(자료 덮고 쓰기 / AI 답 토글에 숨기기)는 이 실습의 정체성이다. 형태가 바뀌어도 이 둘은 남겨야 한다
- **드리프트 사양 0.5℃/h · 62→64℃ · 80℃ 미도달**은 절대 변경 금지 (전 일차 서사가 걸려 있음)
- 슬라이드는 **대본을 대신해야 한다** — 사용자는 대본을 안 읽는다
- 학생 이탈 방지가 최우선 — **쉽고 천천히**, 쓸데없는 구간 없이
