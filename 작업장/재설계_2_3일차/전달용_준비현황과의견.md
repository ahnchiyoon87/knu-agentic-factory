## 3. 수정 의견 4가지

### 의견 1. Day 2 시간이 빠듯합니다

노션 1교시를 빼면 실습이 세 교시(150분)인데, 그 안에
「파이썬 브리핑 + 데이터 생성기 작성 + 고장 주입 + 규칙 작성」은 1학년 기준으로 어렵습니다.

**제안** — 데이터 생성기는 이미 있으니 **"직접 만든다"가 아니라 "돌려보고 관찰한다"** 로 바꾸면
시간이 맞습니다. 학생이 손으로 하는 건 규칙 작성(4교시)에 집중시키는 게 좋겠습니다.
그쪽이 실패 체험이라 더 중요한 구간이기도 합니다.

### 의견 2. Day 3 훅의 "3초"는 구분이 필요합니다

- **과거 7일치를 한 번에 검사** → 실제로 **3초** 걸립니다 (6만 행 기준). 훅으로 써도 됩니다
- **실시간으로 도는 공장에서 잡기** → **1~3분** 걸립니다

시연 때 둘이 섞이면 "왜 안 잡히지?" 하는 어색한 침묵이 생깁니다.
**훅은 과거 데이터 배치 검사로** 잡는 걸 권합니다.

### 의견 3. Day 3 4교시(팀 데모 50분)가 부족합니다

팀이 에이전트를 완성해서 데모까지 하려면 저희 실측으로는 **최소 90분**이 필요합니다.

**선택지 두 가지**
- (A) 3교시와 4교시를 묶어 100분 실습 + 데모로 재배치
- (B) 4교시는 **강사 시연 + 팀별 짧은 발표**로 축소하고, 팀 완성은 본 과정으로 넘김

### 의견 4. Day 3 → Day 4 연결을 살짝 바꾸면 훨씬 강해집니다

초안의 클리프행어가 **"우리 AI가 한 건 결국 문서 발행입니다"** 인데,
저희가 만든 AI는 **이미 설비를 실제로 조작합니다.**

실제로 이렇게 돕니다:
```
고장 주입 → AI가 감지 → 원인 추정 → 기계 속도 자동 감속
→ "정비 로봇을 보낼까요? 되돌릴 수 없는 행동입니다" → 사람 승인
→ 로봇 이동 → 온도 실제 하강 (63℃ → 53℃)
```

**제안** — Day 3에서 이 장면을 보여주고, Day 4를 이렇게 받으면 어떨까요?

> "어제 AI가 설비를 세웠죠. 근데 그건 **가상 공장**이라 가능했던 겁니다.
> 진짜 공장에선 그 명령이 PLC를 거쳐야 하고, 안전 인터록은 결국 하드웨어에 남습니다."

"문서만 발행했다"보다 **"가상에선 됐는데 진짜는 다르다"** 가 학생에게 더 와닿고,
PLC 세션의 무게도 오히려 올라갑니다.
