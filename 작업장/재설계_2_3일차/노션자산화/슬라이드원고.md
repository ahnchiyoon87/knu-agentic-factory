# 노션 자산화 — 슬라이드 원고 v2 (2일차 1교시 · 60분 · 40장)

> **구성** 서론(문제→해법→도구) 5분 → 본체(기능 쓰면서 자산화) 45분 → 마무리 10분
> **원칙** 감성 멘트 없이 담백하게. 기능 하나 쓸 때마다 **그 결과물 화면**이 바로 따라 나온다.
> `[화면]` = 노션 목업 슬라이드 (여기가 학생 체크포인트. 띄워둔 채로 따라 하게 함)
> `[실물]` = 슬라이드 내리고 강사가 노션 직접 조작
> **노션 AI 기능은 쓰지 않는다. 전부 손으로.**

# 본체 2 — 카드 표 만들기 (10분 · 6장)

### S14 · 왜 표로 만드나
개념을 카드 한 장씩으로 쪼개면
**나중에 "안 끝난 것만" 골라 볼 수 있습니다.**

메모로 쭉 쓰면 그게 안 됩니다.

### S15 · 표 만들기
`[실물]` 시연 1분

`/데이터` → **데이터베이스 - 인라인** → 이름 **💡 개념 카드**

### S16 · `[화면]` 빈 표가 생김
제목만 있고 행이 없는 데이터베이스

### S17 · 속성 두 개 달기
`[실물]` 시연 1분

| 이름 | 유형 | 옵션 |
|---|---|---|
| **이해도** | 선택 | 설명못함 · 대충앎 · 설명가능 |
| **자료** | 텍스트 | 근거 쪽수 |

> 기본으로 있는 「태그」 칸은 지웁니다. **속성은 2개면 충분합니다.**

### S18 · `[화면]` 속성이 생긴 표
이해도 · 자료 열이 추가된 모습

### S19 · 필기의 물음표를 카드로
| 필기 | 카드 제목 |
|---|---|
| "W를 몇으로 ????" | 윈도 크기는 어떻게 정하나 |
| "지금값은 평균에 넣지말라 — 무슨말?" | 왜 지금 값을 평균에서 빼는가 |
| "오탐 미탐 헷갈림" | 오탐과 미탐은 무엇이 다른가 |
| "뭘 골라야 하는거임?" | 결측 처리에 정답이 없는 이유 |

**제목만 먼저.** 내용은 뒤에서 채웁니다.

### S20 · `[화면]` 카드 4장이 들어간 표
전부 「설명못함」 상태

# 본체 3 — 양식 만들기 (8분 · 4장)

### S21 · 매번 같은 구조를 다시 칠 순 없습니다

→ **템플릿을 한 번만** 만듭니다.

### S22 · 카드 양식 4구획
① 🗣 **자료 덮고 설명하면**
② ❓ **이게 없으면 뭐가 안 되나**
③ 💻 **코드로는**
④ ▸ **자료 원문 / 내 필기** (토글)

### S23 · 만드는 법
`[실물]` 시연 2분

**새로 만들기 ▾** → **＋ 새 템플릿** → 4구획 입력
→ 뒤로 → 템플릿 옆 **⋯** → **기본으로 설정**

### S24 · `[화면]` 템플릿 편집 화면
상단에 "개념 카드의 템플릿을 편집하고 있습니다" 배너 + 4구획

> 이 배너가 보이면 제대로 하고 있는 겁니다.

`/토글` → 제목 **자료 원문 / 내 필기** → 안에 원문 붙여넣기
