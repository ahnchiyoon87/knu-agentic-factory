## 지켜야 할 사실 (실습과 어긋나면 수업이 깨집니다)
- 드리프트 사양: 0.5℃/h, 62→64℃, 80℃ 경보선을 끝까지 안 넘음 — 절대 변경 금지
- Day 3 Lab 3-2 실측: 진동 스파이크 3/3 검출 · 온도 드리프트는 못 잡음(z-score 구조적 한계)
  · 임계값 k를 3.0→2.0으로 낮추면 오탐 11배(하루 81건→911건). 이 수치로 오탐↔미탐 슬라이드를 만들 것
- Day 4 제어 도구 4개: set_equipment_speed / stop_equipment / dispatch_robot / ack_alarm
  · HITL: 감속·알람확인은 자동, 정지·로봇파견은 사람 승인 필수
- Day 4 라이브 시연 실측: 주입 → 감지까지 1~3분 → 진단(정비이력 WO-2026-0801 인용) → 감속 자동
  → 승인 요청 → 승인 → 로봇 이동 → 온도 63℃→53℃ 하강. 이 순서가 시연 슬라이드의 뼈대
- Day 2 스펙 껍데기: 빈칸 6곳 + 일부러 틀린 곳 3곳(예: 온도 82℃ 초과 시 알람 '해제')
  · 정답을 알려주지 않고, 틀리게 채우면 오후 구현에서 스스로 드러나게 하는 것이 설계 의도

## 각 날의 '와' 순간 (슬라이드가 이걸 향해 달려가야 함)
- Day 2: 어제 무너뜨린 요구사항을 스펙으로 처리하니 안 무너진다
- Day 3: 내가 짠 알고리즘을 AI가 도구로 집어 쓴다
- Day 4: 내 팀 AI가 공장을 실제로 움직인다 (승인 → 로봇 출동)

## 작업 방식
- 교안의 장별 내용을 벗어나지 말 것. 수치·순서·이름 임의 변경 금지
- 실습 화면 캡처가 필요하면 특강 1주 전(D-7) 최종 촬영이 원칙 — 지금은 자리만 잡아둘 것
- 완성되면 산출물/N일차_*/ 에 넣고, 저장소 README의 슬라이드 상태를 갱신할 것
