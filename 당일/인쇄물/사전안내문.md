# [사전 안내] 경남대 RISE 피지컬AI 사관학교 — 8월 AI 특강 준비 안내

안녕하세요. 특강에서 여러분은 **AI에게 말로 시켜서, 가상 공장을 감시하고 움직이는
시스템을 이틀 만에 직접 만들게 됩니다.** 첫날 수업이 바로 실습으로 시작되므로,
아래 준비를 **특강 전날까지** 꼭 마쳐 주세요. 15~20분이면 됩니다.

> 준비가 안 된 채 오시면 첫날 첫 시간을 설치로 보내게 되어 실습 진도를 놓칩니다.
> 막히는 부분은 그대로 두고 오셔도 됩니다 — 첫날 셋업 시간에 도와드립니다.
> 단, **아래 ①~⑦을 시도는 해 보고 오는 것**이 중요합니다.

---

## 준비물

- 노트북 (Windows 10/11 또는 macOS) — **관리자 권한으로 프로그램 설치가 가능해야 합니다**
- 크롬(Chrome) 브라우저
- 전원 어댑터 (4시간 연속 사용)

## ① Python 설치 (3분)

1. https://www.python.org/downloads/ 에서 **Python 3.12** 다운로드 후 실행
2. 설치 첫 화면에서 **"Add python.exe to PATH" 체크박스를 반드시 체크** 후 Install
3. 확인: 명령 프롬프트(cmd)를 열고 `python --version` 입력 → `Python 3.12.x` 가 나오면 성공

## ② Git 설치 (3분)

1. https://git-scm.com/downloads 에서 다운로드 후 실행 (설정은 전부 기본값으로 Next)
2. 확인: 명령 프롬프트에서 `git --version` 입력 → 버전이 나오면 성공

## ③ GitHub 계정 (5분)

1. https://github.com 에서 **Sign up** — 개인 이메일로 가입
2. 아이디는 특강 후에도 **포트폴리오 주소**가 되니 신중히 정하세요 (예: hong-gildong)
3. 확인: 로그인해서 내 프로필 페이지가 열리면 성공

> 이틀 동안은 **여러분이 저장소를 만들 일이 없습니다.** 코드를 올리지 않습니다.
> 계정은 9월 본과정에서 포트폴리오로 쓰려고 미리 만들어 두는 것입니다.

## ④ VS Code 설치 (3분)

1. https://code.visualstudio.com 에서 다운로드 후 설치 (기본값으로)
2. 확인: 실행해서 창이 열리면 성공

## ⑤ VS Code에 Claude(AI 코딩 도우미) 설치 (5분)

1. VS Code 왼쪽의 블록 모양 아이콘(Extensions) 클릭
2. 검색창에 `Claude Code` 입력 → 설치(Install)
3. 왼쪽에 생긴 Claude 아이콘 클릭 → 안내에 따라 **로그인**
   - 계정: **우리 쪽에서 발급해 드립니다.** 첫날 안내해 드리는 계정으로 로그인하세요.
     (개인 계정을 이미 쓰고 계시면 그대로 쓰셔도 됩니다)
   - `[■ 발급 방식 확정 대기 — 39명이 동시에 쓰므로 계정 1개 공유는 불가(세션 충돌·약관).`
     `조직 플랜에서 좌석 39개를 발급하는 형태여야 함. 좌석 확보 확인 후 이 문단의 배부 절차를 확정]`
4. 확인: 채팅창에 `안녕` 이라고 쳐서 답이 오면 성공

## ⑥ 실습 저장소 내려받기 (3분)

첫날 첫 시간에 바로 여는 폴더입니다. **미리 받아 두면 당일 5분을 아낍니다.**

1. **VS Code 를 열고** 메뉴에서 `터미널 → 새 터미널` 을 누른 뒤, 아래를 그대로 입력

   ```
   cd ~
   git clone [■ 저장소 주소 — 강사가 확정 후 기입]
   ```

   > 바탕화면에 받지 않는 이유 — OneDrive 가 켜져 있으면 바탕화면 경로가
   > `OneDrive\바탕 화면` 처럼 한글에 띄어쓰기까지 들어가서 `cd Desktop` 이 안 먹습니다.
   > `cd ~` 는 어느 PC 에서든 됩니다.

2. 확인: `k-precision-lab` 폴더가 생기고, 그 안에 **`1일차` `2일차` `데이터`**
   세 폴더가 보이면 성공입니다. (폴더가 생긴 위치는 화면에 찍힌 경로로 확인)

3. VS Code 에서 **그 `k-precision-lab` 폴더를 엽니다.** (파일 → 폴더 열기)

> **여러분이 저장소를 만들거나 올릴 일은 없습니다.** 받아서 고치기만 합니다.
>
> `git` 이 막히거나 위 명령이 안 되면 — **ZIP 으로 받으셔도 됩니다.**
> `[■ 구글드라이브 링크 — 강사가 확정 후 기입]`
> 압축을 풀고 나온 `k-precision-lab` 폴더를 아무 데나 두고 VS Code 로 열면 똑같습니다.
> 둘 다 안 되면 **그대로 오세요.** 첫날 USB 로 드립니다.

## ⑦ 필요한 라이브러리 미리 설치 (2분)

첫날 첫 실습이 **7일치 센서 데이터 6만 행**을 읽는 것으로 시작합니다.
그때 쓰는 라이브러리를 **미리** 깔아 두세요. 강의장에서 39명이 동시에 받으면 느립니다.

1. ⑥ 에서 받은 폴더를 **VS Code 로 열고**, 터미널에 그대로 입력 (제일 확실합니다)

   ```
   cd 1일차/실습
   pip install -r requirements.txt
   ```

   > VS Code 로 폴더를 열면 터미널이 **이미 그 폴더에서** 시작합니다.
   > 그래서 긴 경로를 칠 필요가 없습니다.

   ⑥ 이 안 됐으면 이것만이라도 — `python -m pip install pandas httpx`

2. 확인: 아래를 입력해 **버전 숫자가 두 줄 나오면 성공**

   ```
   python -c "import pandas, httpx; print(pandas.__version__, httpx.__version__)"
   ```

> `pip 은(는) 내부 또는 외부 명령... 이 아닙니다` 가 뜨면 ① 의 **PATH 체크**를 안 한 것입니다.
> Python 을 지우고 다시 설치하면서 **"Add python.exe to PATH"** 를 체크하세요.
>
> 첫날 실습가이드에도 같은 명령이 한 번 더 있습니다. 미리 깔아 두면 몇 초 만에 끝납니다.
> **안 깔고 오시면 첫 명령에서 `ModuleNotFoundError` 로 바로 멈춥니다** —
> `pandas` 는 데이터를 읽는 데, `httpx` 는 내 공장 번호를 받아 오는 데 씁니다.
