**학생은 저장소를 만들지 않습니다.** 받아서 고치기만 합니다. 올리는 단계가 없습니다.

| **1일차 맨 처음** | **`python 내번호.py`** — 내 공장을 받는다 (번호가 화면에 뜸) | `1일차/실습` |
| **1일차 오전** | 그 화면에 찍힌 주소로 **내 공장** 열기 (크롬) | — |

| **2일차 끝** | 노션 링크 제출 = 수료 | — |

**번호는 학생이 직접 받습니다 — 종이로 나눠 주지 않습니다.**

`python 내번호.py` 를 치면 서버가 **아직 안 나간 공장 하나**를 그 PC 에 붙여 줍니다.
번호·접속 키·서버 주소가 **2일차 설정 파일까지 자동으로 채워집니다.**
학생이 손으로 옮겨 적을 것이 없습니다.

| 학생 상황 | 시킬 말 |
|---|---|
| 번호를 잊었다 | `python 내번호.py` 를 그냥 다시 치세요 — **같은 번호**가 나옵니다 |
| 자리를 옮겼다 · 컴퓨터를 바꿨다 | `python 내번호.py S07` — 그 공장을 그대로 가져옵니다 |
| 「남은 공장이 없습니다」 | 강사가 `python tools/자리배정.py --풀기 S07` 로 안 쓰는 번호를 풉니다 |

**끊기면 안 되는 고리 하나**

**`1일차/실습` 폴더** — 2일차 오전이 그 안의 `detect.py` 를 **그대로 import 합니다.**
지우거나 저장소를 다시 받으면 어제 것이 날아갑니다. 1일차 마칠 때 말해 두세요.
(번호는 안 날아갑니다 — `python 내번호.py S07` 로 되찾습니다.)

**막힌 학생은 어디서든 다음으로 갑니다** (아래 「못 끝낸 학생」 참조).
1일차를 못 끝내도 2일차를 시작할 수 있습니다 — `점검.py --열기` 로 채우고 넘어갑니다.

## 학생이 실습 코드를 받는 법 — 개인 저장소는 만들지 않습니다

이틀 동안 학생이 **코드를 올리는 단계가 한 번도 없습니다.** 제출은 노션 링크입니다.
그러니 fork·개인 레포를 시키지 마세요 — GitHub 계정 문제로 39명이 갈립니다.

| 경로 | 언제 | 무엇 |
|---|---|---|
| **① git clone** (기본) | 사전안내문 ⑥ 으로 **미리** | `git clone <저장소 주소>` → 바탕화면에 `k-precision-lab` |
| **② 구글드라이브 ZIP** (예비) | 당일, git 이 막힌 학생 | 링크 하나 던지면 됩니다. 압축 풀면 한글 폴더명 그대로 나옵니다(확인함) |
| **③ USB** (최후) | 네트워크가 통째로 막혔을 때 | 폴더를 복사해 주고 바탕화면에 붙여넣게 합니다 |

**①이 기본인 이유** — 코드와 실습가이드가 같은 폴더에 있어 학생이 두 군데를 오갈 필요가 없고,
수업 중 오타를 고치면 학생이 `git pull` 한 번으로 받습니다.
드라이브는 39명 권한 공유가 또 하나의 갈리는 지점이라 **예비**로만 씁니다.

**학생용 가이드는 따로 나눠 줄 것이 없습니다.** 저장소 안에 `1일차/실습가이드.md`,
`2일차/실습가이드.md` 로 들어 있고, 슬라이드(1일차 16·28장 · 2일차 17·29장)가
**"실습가이드.md 를 열어 두고 따라오라"** 고 화면으로 말합니다. 인쇄 필요 없습니다.

배포본은 **`백스테이지/배포본만들기.py` 로 뽑습니다.** 손으로 만들지 마세요 —
한 번 그렇게 했다가 이쪽 구조가 바뀌었는데 저쪽이 안 따라와 통째로 어긋난 적이 있습니다.

```bash
cd 강사용
python 배포본만들기.py --검증        # 뽑고, 학생 조건(cp949)으로 실제로 돌려 확인
```

폴더에 `1일차` `2일차` `데이터` 세 개가 보이면 맞습니다. **`강의자료` 는 안 들어갑니다.**
`정답/` 은 **일부러 같이 들어갑니다** — 막힌 학생의 `--열기` 가 그걸 읽습니다.

## 제어 개방 — 덱 「지금 제어 권한이 열렸습니다」 슬라이드에서

```bash
python tools/제어개방.py
```

- 제어 API 개방(`tenant_id="*"` — **개인 공장 39개 전부**) + 배속 x120.

> 슬라이드를 넘기면서 실제로 누르는 것이 가장 좋습니다. "지금 열렸습니다" 가 사실이 됩니다.

## 폐루프 주입 — 39명 동시 (§2-3)

전원이 `python loop.py` 를 돌린 것을 확인한 뒤:

```bash
python tools/제어개방.py --inject-all --stagger 2
```

- **`--stagger 2` 를 빼지 마세요.** 동시에 넣으면 감지가 한꺼번에 몰려 진단 호출이
  같은 순간에 나갑니다 — 중앙 3.8초가 15.8초까지 늘어납니다. 2초씩 벌리면 39명이
  넉넉히 들어갑니다(전체 약 81초).
- 배속 x120 기준 **감지까지 약 100초**. x60 이면 약 190초.
- 그 사이 터미널이 조용한 것이 정상이라고 **미리** 말해 두세요. 안 그러면 39명이 동시에 손을 듭니다.

> ### ★ 순서를 바꾸지 마세요 — **먼저 돌리게 하고, 그다음 주입**
>
> 주입은 **가상 5시간짜리**라 배속 x120 에서 **실제 150초면 끝납니다**
> (램프 4시간 + 유지 1시간). 끝나면 온도가 5초 만에 원래대로 돌아갑니다.
>
> | 배속 | 감지까지 | **주입이 끝나는 때** |
> |---|---|---|
> | x120 | 약 100초 | **150초** |
> | x60 | 약 190초 | 300초 |
>
> **주입을 먼저 하고 학생이 나중에 `loop.py` 를 돌리면 이미 끝나 있어서 영영 못 봅니다.**
> 화면에는 「감지 이상 없음」만 계속 찍히고, 학생은 자기 코드가 틀린 줄 압니다.
> (루프가 35·40·45회차에 "강사가 아직 주입을 안 했거나…" 를 스스로 말해 주긴 합니다.)
>
> **늦게 온 학생 한 명에게는** `python tools/제어개방.py --inject S07` 로 그 사람만 다시 넣으세요.
