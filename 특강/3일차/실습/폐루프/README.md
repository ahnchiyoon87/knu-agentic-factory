## 오늘 열리는 것 — 제어 MCP 도구 4개

지금까지 잠겨 있던 제어 통로 네 개가 **MCP 도구 형태로** 열립니다.

```
set_equipment_speed(id, rpm)      감속
stop_equipment(id)                정지
dispatch_robot(robot_id, target)  로봇 파견
ack_alarm(id)                     알람 확인
```

오전에 만든 도구는 **읽는 손**이었습니다. 조회만 했습니다.
오늘 열리는 이 네 개가 **움직이는 손**입니다.

이 도구들은 `control_mcp.py` 에 **완성되어 있습니다.** 강사가 열어 주는 것이라 채울 자리가 없습니다.
`python control_mcp.py --check` 로 연결만 확인해 보세요.

2일차 까지 에이전트는 **제안만** 했습니다. 오늘은 움직입니다.

## 기본 미션 (60분 목표)

강사가 시연한 것과 똑같은 **감지 → 진단 → 조치** 폐루프를 내 공장에서 돌립니다.

### 준비 (5분)

```bash
pip install -r requirements.txt
```

`config.json` 위쪽 세 줄은 **어제 `내번호.py` 가 채워 뒀습니다.** 확인만 하세요.

```json
"tenant":     "S07",
"access_key": "영문·숫자로 된 긴 문자열",
"base_url":   "http://192.168.0.10:8000"
```

> 비어 있으면 `2일차/실습` 에서 `python 내번호.py` 를 한 번 치세요.

```bash
python loop.py --check
```

`제어 통로가 아직 잠겨 있습니다` 가 나오면 강사에게 제어 개방을 요청하세요.

### 채우는 자리 — ★ 세 곳

| 파일 | 함수 | 무엇을 정하는가 |
|---|---|---|
| `agents/detector.py` | `judge()` | **무엇을 이상으로 볼 것인가** |
| `agents/diagnoser.py` | `build_prompt()` | **진단 에이전트에게 뭐라고 지시할 것인가** |
| `agents/actuator.py` | `to_commands()` | **제안을 어떤 명령으로 바꿀 것인가** |

오케스트레이터(`loop.py`)·공장 창구(`factory_api.py`)·승인 관문(`hitl.py`)은 **이미 되어 있습니다.**

```bash
python loop.py --once     한 바퀴
python loop.py            계속
```

> **`judge()` 부터 채우세요.** 감지가 아무것도 못 잡으면 뒤의 두 자리는 불리지도 않습니다.
> 순서대로 하면 한 자리씩 화면에서 확인하며 갈 수 있습니다.

## 왜 네 조각으로 쪼갰는가

교안 4~7장 그대로입니다. 오전에 배운 **Orchestrator-Worker** 패턴을 여기서 손으로 만듭니다.

```
        오케스트레이터 (loop.py)
        누가 무슨 일을 하는지 모른다. 등록표만 본다.
                │
   ┌────────────┼────────────┐
  감지         진단          조치
 무엇이       왜 그런가     명령으로 바꿔
이상한가      무엇을 할까     실행한다
```

각자 **한 가지만** 합니다. 그래서 틀린 자리가 보이고, 그 자리만 고칠 수 있습니다.
오전에 본 "다 하는 에이전트"와의 차이가 정확히 이것입니다.

---

## 감지 — 어제 것을 그대로 쓰면 안 잡힙니다

2일차의 이동창 z-score 는 **창 안에서 튀는 값**을 찾습니다.
드리프트는 창까지 같이 올라가서, 창 기준으로는 언제나 평범합니다.

같은 데이터를 두 방식으로 재 본 실측입니다.

| | 드리프트 있음 | 드리프트 없음 |
|---|---|---|
| 어제의 z-score (k=3) | 2건 | 2건 |
| 오늘의 기준 (창 밖 비교) | **+1.06℃ 검출** | 미검출 |

z-score 는 드리프트가 있으나 없으나 같은 수를 냅니다 — **구분하지 못한다**는 뜻입니다.
그래서 오늘은 창 안이 아니라 **창 밖과 비교**합니다.

**단, 창을 잘라야 합니다.** 루프를 오래 돌리면 창이 계속 길어지는데 드리프트는 그 안의
짧은 구간일 뿐이라, 자르지 않으면 12분쯤부터 차이가 +0.50℃ 로 주저앉아 **미탐이 됩니다.**
`config.json` 의 `detect.window_samples` 가 그 상한입니다.

> **시뮬레이터는 오후에 배속 ×120 으로 올라갑니다** — 공장 4시간이 실제 2분입니다.
> 데이터는 1초에 한 줄씩 들어오고, 그 한 줄이 공장 1분치입니다(부록 A CSV 와 같은 격자).
> 배속이 1이면 드리프트가 실제로 4시간 걸려 안 잡힙니다 — `loop.py --check` 가 경고합니다.

## 승인 관문 — 이건 우리가 정하는 게 아닙니다

교안 10~11장이 못 박은 규칙입니다.

| 명령 | | 왜 |
|---|---|---|
| `set_equipment_speed` | **자동** | rpm 을 되돌리면 그만입니다 |
| `ack_alarm` | **자동** | 되돌릴 수 있습니다 |
| `stop_equipment` | **사람 승인** | 라인이 섭니다 |
| `dispatch_robot` | **사람 승인** | 로봇이 이미 움직입니다 |

갈림은 **되돌릴 수 있는가**입니다. `hitl.py` 가 강제하므로 조치 에이전트에서 우회할 수 없습니다.
바꾸려면 `config.json` 의 `hitl` 만 고칩니다.

```
──────────────────────────────────────────────────────────────
  승인 요청 — 되돌릴 수 없는 행동입니다
    명령   dispatch_robot(AMR-01)
    내용   AMR-01 → EQ-03 로 이동
    이유   미완 정비 작업지시가 원인일 수 있어 현장 확인이 필요합니다.
──────────────────────────────────────────────────────────────
  승인하시겠습니까? [y/N]
```

## 진단 에이전트 — 실제 모델이 진단합니다

**여러분은 API 키를 넣지 않습니다.** 진단 호출은 **강사 서버가 대신** 합니다.

```
내 loop.py ──(내 접속 키)──> 강사 서버 ──(강사 키)──> 실제 모델
```

`config.json` 의 `diagnose.backend` 가 `"server"` 인 것이 그 뜻입니다. **그대로 두세요.**
`내번호.py` 가 채워 준 `access_key` 로 서버가 여러분을 알아봅니다.

**여러분이 쓴 지시문이 그대로 올라갑니다.** 서버는 중계만 하고 문장을 만들지 않습니다.
그래서 `build_prompt()` 를 어떻게 쓰느냐가 결과를 바꿉니다 — 그게 오늘 오후의 핵심입니다.

| `diagnose.backend` | |
|---|---|
| **`server`** (기본) | 강사 서버가 중계. **이걸로 씁니다** |
| `rules` | AI 없이 규칙으로. **강사 안내가 있을 때만** |

> 터미널에 `원인(rules)` 라고 찍히면 **AI 진단을 못 받은 것**입니다.
> 폐루프는 끝까지 돌지만 오늘 봐야 할 장면(AI 가 정비 이력을 읽고 원인을 대는 것)이
> 안 나옵니다. **조용히 넘어가지 말고 손 드세요.**

우리가 쓴 지시문과 받은 진단은 `실행기록.jsonl` 에 회차마다 남습니다.

## 막혔을 때

| 증상 | 원인 | 조치 |
|---|---|---|
| `공장에 닿지 못했습니다` | 주소·네임스페이스 오타 | `config.json` 의 `base_url`·`tenant` |
| `제어 통로가 아직 잠겨 있습니다` | 제어 미개방 | 강사에게 개방 요청 |
| `401 X-Access-Key` | 키 오타 또는 다른 사람 키 | `2일차/실습` 에서 `python 내번호.py` 를 다시 치세요 |
| `NotImplementedError` | ★ 세 자리 중 하나가 비었음 | 화면에 어느 함수인지 나옵니다 |
| 감지가 아무것도 못 잡음 | 강사가 아직 주입 안 함 / 임계 높음 | `detect.drift_delta_c` 를 내려 보세요 |
| 6대가 전부 이상으로 나옴 | 임계가 너무 낮음 | `drift_delta_c` 를 올리세요 |
| 진단이 근거를 지어냄 | 지시문에 "자료 밖은 쓰지 마라"가 없음 | `build_prompt()` 를 다시 보세요 |
| 승인 물음에 답할 수 없음 | 파이프로 실행 중 | 터미널에서 직접 실행하세요 |

**막히면 손을 드세요.** 혼자 20분 붙잡고 있는 것이 제일 손해입니다.
`동작보장_최소경로.md` 를 먼저 보고 쓰세요.

**시간이 다 됐는데도 막혀 있으면** — 막힌 자리 **하나만** 완성본으로 채워서 돌립니다.

```bash
python loop.py --열기 1     감지(judge) 만
python loop.py --열기 2     진단(build_prompt) 만
python loop.py --열기 3     조치(to_commands) 만
```

> 나머지 자리는 여러분이 쓴 것 그대로 돕니다. **파일은 안 고칩니다** —
> 옵션을 빼면 다시 내 코드로 돌아옵니다.
> 오늘 목표는 세 자리를 혼자 채우는 게 아니라 **공장이 실제로 움직이는 것을 보는 것**입니다.
