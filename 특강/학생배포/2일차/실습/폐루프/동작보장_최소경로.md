## 1. 감지 (15분) — `agents/detector.py` 의 `judge()`

세 자리 중 **여기부터**입니다. 감지가 아무것도 못 잡으면 진단도 조치도 불리지 않습니다.

```bash
python loop.py --once
```

`감지  이상 1건` 이 나오면 다음으로.

| 증상 | 조치 |
|---|---|
| `NotImplementedError: judge` | 아직 안 채웠습니다 |
| `감지  이상 없음` 만 반복 | ① `loop.py --check` 에 `배속 x1.0` 이 나오면 강사에게 요청하세요 (기본은 ×60 입니다)<br>② 강사가 아직 주입을 안 했을 수 있습니다 — 2D 뷰에서 온도를 보세요<br>③ `detect.drift_delta_c` 를 `0.4` → `0.3` 으로 내려 보세요 |
| 오래 돌리니 안 잡히기 시작 | `judge()` 에서 **최근 `window_samples`×2 개만 자르는 부분**이 빠졌습니다 (아래 참고) |
| 6대가 **전부** 이상 | 임계가 너무 낮습니다. `drift_delta_c` 를 올리세요 |
| `표본이 모자라` | `watch.minutes` 를 늘리세요 (기본 12) |

**실측 (배속 ×120)**

| | 주입 후 |
|---|---|
| 갓 켠 경우 | **40초**부터 잡힘 |
| 계속 돌리던 경우 (창이 꽉 참) | **90~230초** 사이에 잡힘 |
| 평온할 때 오탐 | 최대 0.08℃ — 임계 0.4℃ 의 **5배 여유** |

> **오래 돌리면 안 잡히기 시작하는 함정** — 루프를 계속 돌리면 창이 길어지는데,
> 드리프트는 그 안의 짧은 구간일 뿐이라 앞뒤 평균 차이가 희석됩니다.
> 자르지 않으면 12분쯤부터 차이가 **+0.50℃** 로 주저앉아 임계를 못 넘습니다.
> `judge()` 에서 **최근 것만 남기고 자르십시오.**

## 그래도 안 될 때 — 최소 동작 조합

시간이 없으면 이 조합까지만으로 넘어가십시오 — 이것만으로도 폐루프는 성립합니다.

| 최소로 필요한 것 | |
|---|---|
| `judge()` | **필수** — 없으면 아무것도 시작되지 않습니다 |
| `build_prompt()` | 문자열 두 개만 돌려주면 됩니다. 규칙 진단이 받쳐 줍니다 |
| `to_commands()` | **감속 하나만** 만들어도 폐루프는 성립합니다 |

**가장 짧은 `to_commands()`** — 감속 하나. 이것만으로 감지 → 진단 → 조치가 닫힙니다.

```python
def to_commands(diagnosis, finding, cfg):
    rpm = finding.get("current_rpm")
    if not rpm:
        return []
    target = max(float(cfg["min_rpm"]), round(float(rpm) * float(cfg["slow_down_ratio"])))
    return [{"command": "set_equipment_speed", "target": finding["equipment_id"],
             "args": {"rpm": target}, "detail": f"{rpm:.0f} → {target:.0f} rpm",
             "why": "온도 상승을 감속으로 먼저 꺾습니다."}]
```

정지와 로봇 파견은 여기에 없습니다 — **승인 관문을 시연하려면 파견을 하나 더 넣으십시오.**
