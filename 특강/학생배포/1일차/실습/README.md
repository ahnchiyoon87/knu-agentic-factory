## 할 일

`detect.py` 의 **TODO 세 군데**를 채웁니다. 다른 파일은 건드리지 않습니다.

| TODO | 함수 | 무엇 |
|---|---|---|
| 1 | `window_stats()` | 앞 W개로 평균·표준편차 |
| 2 | `is_anomaly()` | z-score 가 k 를 넘는지 판정 |
| 3 | `handle_missing()` | 값이 안 들어온 자리를 어떻게 다룰지 |

```bash
python 내번호.py           # 처음 한 번 — 내 공장을 받는다
python 점검.py             # 막혔을 때 (--힌트 1·2 · --열기 1·2·3)

python run.py              # 내 구현을 7일치 데이터에 돌린다
python run.py --k 2.0      # 임계값을 낮춰서
python run.py --window 30  # 윈도를 짧게
```

데이터는 **K-정밀 7일치 CSV**(60,480행)입니다. 받은 폴더의 `데이터/` 에 들어 있습니다.
심어 둔 이상은 세 가지 — 온도 드리프트 / 진동 스파이크 / 센서 결측.

## 3단계

**Step 1 (25분)** — TODO 세 군데를 채웁니다.
`detect.py` 안에 C 를 하다 온 사람 기준의 파이썬 힌트가 있습니다.

**Step 2 (15분)** — 데이터에 돌려 봅니다. 세 개 중 몇 개를 잡았는지,
그리고 **그 대가로 아닌 것을 몇 번이나 잡았는지**를 함께 봅니다.
`--k` 를 바꿔 가며 감을 잡습니다.

**Step 3 (10분)** — 같은 것을 AI 에게 시켜 만든 구현과 나란히 놓고 비교합니다.
**이 자리는 강사가 화면에서 직접 보여 줍니다.**
**특히 결측 처리**를 봅니다.

## 결과 화면 읽는 법

돌리면 심어 둔 이상 3종마다 이런 줄이 나옵니다.

```
  [O ] …   잡음
  [~ ] …   노이즈 수준 — 못 잡은 것과 같다
  [  ] …   못 잡음
```

`[~ ]` 는 **울리긴 했는데 정상 구간에서 울리는 빈도와 다를 게 없다**는 뜻입니다.
이상 구간에서 몇 번 울렸다고 "잡았다"고 하면 안 됩니다 —
아무 데서나 그만큼 울리고 있으니까요.

**어느 것이 어떻게 나오는지는 직접 돌려서 보세요.** 여기 적지 않습니다.
숫자를 보고 "왜 이렇게 나왔지?" 하는 순간이 오늘 제일 중요한 자리입니다.
