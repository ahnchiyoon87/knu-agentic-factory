https://code.visualstudio.com 에서 **Download for Windows** 를 눌러 받고 실행합니다.
**전부 기본값 그대로 두고 넘어가면 됩니다.** 화면 순서는 이렇습니다.

| 화면 | 할 일 |
|---|---|
| 사용권 계약 | **「동의합니다」** 선택 → 다음 |

| **추가 작업 선택** | **그대로 두세요.** 「PATH에 추가」가 이미 체크돼 있습니다 → 다음 |
| 설치 준비 완료 | **설치** |
| 마법사 완료 | **종료** (「Visual Studio Code 실행」 체크된 채로) |

## ② 실습 파일 받기 (3분)

첫날 첫 시간에 바로 여는 폴더입니다. **미리 받아 두면 당일 5분을 아낍니다.**
**아래 둘 중 편한 쪽 하나만** 하시면 됩니다. 내용은 같습니다.

**방법 A — `git clone`** (git 을 쓰실 줄 알면 이쪽이 빠릅니다)

```
git clone https://github.com/ahnchiyoon87/k-precision-lab.git
```

**방법 B — 구글드라이브에서 ZIP 받기**

1. 아래 폴더에서 **`k-precision-lab.zip`** 을 내려받습니다 (약 1MB)

   https://drive.google.com/drive/folders/1WsQmwnfv21qAbAb79X1BS95djSz0Vvti?usp=sharing

2. **압축을 풉니다.** 위치는 어디든 상관없습니다 (바탕화면·다운로드 폴더 등)

**둘 중 무엇으로 받았든, 이제 VS Code 로 그 폴더를 엽니다**

3. VS Code 를 실행하고 가운데 **「폴더 열기」** 를 누릅니다.

4. 압축을 푼 **`k-precision-lab` 폴더를 한 번 클릭**하고 오른쪽 아래 **「폴더 선택」** 을 누릅니다.
   (폴더 안으로 들어가지 마세요. 폴더 자체를 고릅니다.)

5. 왼쪽 탐색기에 **`2일차` `3일차` `데이터`** 가 보이면 성공입니다.

> **ZIP 으로 받으셨으면 압축을 꼭 풀어서 쓰세요.** ZIP 안에서 바로 열면 코드가 안 돌아갑니다.
> 「폴더 선택」을 눌렀는데 왼쪽에 저 셋이 안 보이면, 한 단계 위나 아래 폴더를 고른 것입니다.
>
> 안 되면 **그대로 오세요.** 첫날 도와드립니다. 여기서 붙잡고 있지 마세요.

## ③ uv 설치하고 한 번 돌려 보기 (5분)

> **왜 이걸 쓰나요 — 실습 폴더마다 「전용 작업대」를 차리는 것입니다.**
> 학교 컴퓨터에 뭐가 깔려 있든, 다른 수업에서 뭘 설치했든 우리 실습은 그 작업대 안에서만 돕니다.
> 그래서 **내 컴퓨터가 어지럽혀지지 않고**, 39명이 **전부 똑같은 환경**에서 같은 결과를 봅니다.
> 그 작업대를 차리고 필요한 도구(파이썬 · 라이브러리)를 가져다 놓는 일을 `uv` 가 대신합니다.

**②에서 연 VS Code 안에서** 합니다. 창을 따로 열 필요 없습니다.

**1. 터미널을 엽니다** — 위 메뉴 **터미널 → 새 터미널** (또는 `Ctrl` + `` ` ``)

**2. 아래 한 줄을 붙여넣고 Enter** — 실습에 쓸 `uv` 를 깝니다.

```
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
```

**3. 터미널을 새로 엽니다** — 방금 깐 것을 인식시키려면 필요합니다.
터미널 패널 오른쪽 **휴지통 아이콘**을 눌러 닫고, 다시 **터미널 → 새 터미널**.

**4. 실습이 돌아가는지 확인합니다**

```
cd 2일차/실습
uv run 점검.py
```

**처음 한 번은 1~2분 걸립니다** — 파이썬과 라이브러리를 이때 갖춥니다.
점검 결과가 화면에 뜨면 성공입니다. (아직 아무것도 안 채웠으니 「[ ]」 표시가 나오는 게 정상입니다.)

> 강의장에서 39명이 동시에 받으면 느립니다. **집에서 미리 한 번 돌려 두세요.**
> `uv` 를 못 찾는다고 나오면 3번(터미널 새로 열기)을 안 한 것입니다.
