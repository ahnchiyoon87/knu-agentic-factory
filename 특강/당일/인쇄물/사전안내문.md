안녕하세요. 특강에서 여러분은 **AI에게 말로 시켜서, 가상 공장을 감시하고 움직이는
시스템을 이틀 만에 직접 만들게 됩니다.** 첫날 수업이 바로 실습으로 시작되므로,
아래 준비를 **특강 전날까지** 꼭 마쳐 주세요. 15~20분이면 됩니다.

> 준비가 안 된 채 오시면 첫날 첫 시간을 설치로 보내게 되어 실습 진도를 놓칩니다.
> 막히는 부분은 그대로 두고 오셔도 됩니다 — 첫날 셋업 시간에 도와드립니다.

> **강사가 화면에서 직접 보여 드립니다.** 여러분은 각자 해 보시고, 막히면

## 준비물

- 노트북 (Windows 10/11 또는 macOS) — **관리자 권한으로 프로그램 설치가 가능해야 합니다**
- 크롬(Chrome) 브라우저
- 전원 어댑터 (4시간 연속 사용)

## ① Python 설치 (3분)

1. https://www.python.org/downloads/ 에서 **Python 3.12** 다운로드 후 실행
2. 설치 첫 화면에서 **"Add python.exe to PATH" 체크박스를 반드시 체크** 후 Install
3. 확인: 명령 프롬프트(cmd)를 열고 `python --version` 입력 → `Python 3.12.x` 가 나오면 성공

## ② VS Code 설치 (3분)

1. https://code.visualstudio.com 에서 다운로드 후 설치 (기본값으로)
2. 확인: 실행해서 창이 열리면 성공

## ③ 실습 파일 받기 (3분)

첫날 첫 시간에 바로 여는 폴더입니다. **미리 받아 두면 당일 5분을 아낍니다.**
**아래 둘 중 편한 쪽 하나만** 하시면 됩니다. 내용은 같습니다.

**방법 A — `git clone`** (git 을 쓰실 줄 알면 이쪽이 빠릅니다)

```
git clone https://github.com/ahnchiyoon87/k-precision-lab.git
```

**방법 B — 구글드라이브에서 ZIP 받기**

1. 아래 폴더에서 **`k-precision-lab.zip`** 을 내려받습니다 (약 1MB)

   https://drive.google.com/drive/folders/1WsQmwnfv21qAbAb79X1BS95djSz0Vvti?usp=sharing

2. **압축을 풉니다.** 위치는 어디든 상관없습니다 (바탕화면·다운로드 폴더 등)

**둘 중 무엇으로 받았든 마지막에 이것만 확인하세요**

3. `k-precision-lab` 폴더 안에 **`1일차` `2일차` `데이터`** 세 폴더가 보이면 성공입니다

4. **VS Code 에서 그 `k-precision-lab` 폴더를 엽니다.** (파일 → 폴더 열기)

> **ZIP 으로 받으셨으면 압축을 꼭 풀어서 쓰세요.** ZIP 안에서 바로 열면 코드가 안 돌아갑니다.
>
> 안 되면 **그대로 오세요.** 첫날 USB 로 드립니다. 여기서 붙잡고 있지 마세요.

## ④ 필요한 라이브러리 미리 설치 (2분)

첫날 첫 실습이 **7일치 센서 데이터 6만 행**을 읽는 것으로 시작합니다.
그때 쓰는 라이브러리를 **미리** 깔아 두세요. 강의장에서 39명이 동시에 받으면 느립니다.

1. ③ 에서 받은 폴더를 **VS Code 로 열고**, 터미널에 그대로 입력 (제일 확실합니다)

   ```
   cd 1일차/실습
   pip install -r requirements.txt
   ```

   > VS Code 로 폴더를 열면 터미널이 **이미 그 폴더에서** 시작합니다.
   > 그래서 긴 경로를 칠 필요가 없습니다.

   ③ 이 안 됐으면(폴더를 못 받았으면) 이것만이라도 — `python -m pip install pandas httpx`

2. 확인: 아래를 입력해 **버전 숫자가 두 줄 나오면 성공**

   ```
   python -c "import pandas, httpx; print(pandas.__version__, httpx.__version__)"
   ```

> `pip 은(는) 내부 또는 외부 명령... 이 아닙니다` 가 뜨면 ① 의 **PATH 체크**를 안 한 것입니다.
> Python 을 지우고 다시 설치하면서 **"Add python.exe to PATH"** 를 체크하세요.
>
> 첫날 실습가이드에도 같은 명령이 한 번 더 있습니다. 미리 깔아 두면 몇 초 만에 끝납니다.
> **안 깔고 오시면 첫 명령에서 `ModuleNotFoundError` 로 바로 멈춥니다** —
> `pandas` 는 데이터를 읽는 데, `httpx` 는 내 공장 번호를 받아 오는 데 씁니다.
