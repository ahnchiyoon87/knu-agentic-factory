# 폐루프 — 강사 쪽 우회 (학생이 할 수 없는 것)

> 원래 학생용 `동작보장_최소경로.md` 뒤에 붙어 있었다.
> 거기 있으면 학생이 `loop.py --use-answers`(세 자리 전부 정답)를 보게 되어
> 실습이 통째로 무의미해진다. 그래서 강사용으로 떼어 냈다.

**2일차 준비는 명령 하나입니다** — 시뮬레이터 폴더에서:

```bash
python tools/제어개방.py            # 제어 개방 + 배속 120
python tools/제어개방.py --inject-all  # 개인 공장 전체에 주입
python tools/제어개방.py --status      # 지금 뭐가 빠졌는지
python tools/제어개방.py --end         # 제어 잠금 상태로 되돌림
```

| 상황 | 강사 조치 |
|---|---|
| 라이브 시연(교안 12~14장)을 돌려야 함 | `python loop.py --use-answers` — 참고 답안으로 완성된 폐루프가 돕니다 |
| 제어 통로가 잠김 | `python tools/제어개방.py` |
| 학생이 자기 번호를 잊음 | 학생이 `python 내번호.py` 를 다시 돌리면 그대로 나옵니다. 노트북을 바꿔 왔으면 `python 내번호.py S07` |
| 주입이 안 보임 | `python tools/제어개방.py --inject S07` (전체는 `--inject-all --stagger 2`). **배속 x120 에서 주입은 150초면 끝납니다** — 학생이 늦게 돌렸으면 다시 넣어 주세요 |
| 공장이 엉킴 | `POST /api/instructor/reset?tenant_id=S07` — 이력·알람·명령·주입이 지워지고 상태가 새로 생깁니다 |

> 강사 콘솔(`--status`)이 **빠뜨린 것을 스스로 말합니다** — 제어를 열었는데 배속이 1이거나,
> 제어는 열렸는데 주입이 없으면 경고가 뜹니다. 교안에 없는 항목이라 교안이 안 알려주기 때문입니다.

> **배속은 기울기를 바꾸지 않습니다.** 샘플당 상승폭은 그대로고 샘플이 더 빨리 나올 뿐입니다.
> 그래서 배속을 올려도 "드리프트는 미묘하다"는 1일차의 전제가 깨지지 않습니다.
