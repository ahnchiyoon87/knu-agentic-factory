## 제일 알고 싶은 것

**실제 설비 고장은 정말 「티가 안 나게」 시작하는가?**

이게 사실이 아니면 학생이 4시간을 들여 알고리즘을 짤 이유가 없습니다.

우리 쪽 실측은 이렇습니다.

| | 값 |
|---|---|
| 노이즈 σ | 0.35℃ |
| 2분간 — 이상이 든 기계 | **+0.47℃** |
| 2분간 — 멀쩡한 기계 5대 | −0.60 / −0.23 / +0.40 / −0.63 / +0.02 |
| 7일치에서 z-score 판정 | 드리프트 \|z\| **0.94** vs 정상 **0.81** → **구별 안 됨** |
| 7일 내내 80℃ 초과 | **0행** |

**이상보다 정상의 흔들림이 더 큽니다.** 이것이 실제 설비에서도 그러한지가 핵심 질문입니다.

## 이미 본 것 — 다시 안 가져와도 됩니다

**국제표준 (강한 근거)**
- ISO 13373-1 — *"추세 분석은 안정된 기준선을 세우고 유의한 이탈을 찾는 것.
  **변화를 잡아내는 것이 절대값보다 중요한 경우가 많다**"*

**업체 자료 (약한 근거 — 1차 출처 아님)**
- 「하루 0.3℃ 드리프트」, 「기준선 +2~5℃ 가 주의」, 62℃ 설비 냉각 막힘 사례
- 전부 베어링 정비 업체·예측정비 SaaS 의 마케팅·안내 페이지. 근거 미제시

**주제가 달랐던 것**
- MDPI 등 학술 논문은 **정상 운전 시 열변형 보정**(예열 3.5시간 안정, 25~28℃ 상승)이라
  **열화로 인한 드리프트 속도**와는 다른 주제

**따라서 필요한 것은** — 학술 논문 · 국제표준 · 공작기계 제조사 문서 ·
공공 run-to-failure 데이터셋(NASA IMS, PRONOSTIA/PHM2012 등)의 **1차 근거**입니다.
