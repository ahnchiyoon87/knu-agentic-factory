실습을 **학생과 같은 조건으로 완주하면서** 아래 순서대로 찍습니다.

**나눠 맡습니다** — **VS Code 터미널·편집기 화면은 강사가** 찍고,
**브라우저 공장 화면은 이미 라이브로 캡처해 넣었습니다.**

**강사가 찍을 것은 15장**입니다. 아래 순서 그대로입니다.
(원래 11장이었는데 — 먼저 찍어 둔 터미널 3장이 **VS Code 가 아니라 단독 터미널 창**이라
규칙 1에 걸려 다시 찍기로 했고, 터미널 여는 법 1장이 새로 늘었습니다 — 2026-08-16.)

**찍는 규칙 넷**

1. **VS Code 화면을 찍습니다.** 따로 띄운 콘솔·cmd 창은 쓰지 않습니다. 학생은 VS Code 안 터미널만 봅니다.
2. **잘라내지 않습니다.** 파일 탭·왼쪽 탐색기·터미널 패널이 같이 보여야 「내가 지금 어디에 있는지」가 전달됩니다.
3. **화면에 나온 그대로 찍습니다.** 글자를 지우거나 덧그리지 않습니다. 붉은 테두리가 필요하면 `제작/빌드도구/그림표시.py` 로 나중에 얹습니다.
4. **에러는 만들지 말고 겪은 것을 찍습니다.** 실습 중 실제로 난 화면이 아니면 넣지 않습니다.

파일은 전부 **`강의/그림/실습/`** 에 넣습니다. 이름을 그대로 맞춰 주세요.
