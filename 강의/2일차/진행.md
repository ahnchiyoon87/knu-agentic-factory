## ★ AI 가 짠 것과 나란히 (실습 2 의 마지막 10분)

**학생 가이드 12번이 "이 자리는 강사가 앞에서 합니다" 라고 적어 두었습니다.**
안 하면 학생 문서가 거짓말이 됩니다. 학생은 보기만 합니다.

**보여 주기만 하면 「AI 가 짰다」는 말만 남습니다. 돌려야 판정이 됩니다.**

### ① 강사 폴더에서 클로드 코드에게 시킵니다

`2일차/실습` 에서 클로드 코드를 열고 아래를 그대로 줍니다.

> detect_ai.py 라는 파일을 새로 만들어 줘. 이동 윈도 z-score 방식의 이상감지다.
>
> 함수는 이것 하나면 된다:
> &nbsp;&nbsp;detect(values, window=60, k=3.0) -> list[bool]
> &nbsp;&nbsp;values 는 float 또는 None 이 섞인 리스트, 반환은 같은 길이의 True/False 리스트.
>
> · 지금 값 바로 앞 window 개로 평균과 표준편차를 낸다 (지금 값은 넣지 않는다)
> · 앞이 모자라면 False
> · z-score 절댓값이 k 를 넘으면 True
> · 값이 없는 자리(None)를 어떻게 다룰지는 네가 정하고, 파일 맨 위 주석에 한 줄로 적어라
>
> 파일만 만들고 다른 설명은 하지 마.

### ② 나온 코드에서 두 곳을 짚습니다

- **표준편차를 무엇으로 나눴나** — 개수(모표준편차)인가, 개수−1(표본)인가
- **값이 없는 자리를 어떻게 했나**

### ③ 같은 데이터에 돌립니다

```
uv run run.py --impl detect_ai
```

**실측(2026-08-16, 강사 PC)** — 이 자리에서 실제로 갈린 숫자입니다.

| | 참고 답안 | AI 가 짠 것 |
|---|---|---|
| 헛울림 비율 | 0.94% | **1.01%** |
| 아닌데 울린 것 | 567행 · 하루 81번 | **609행 · 하루 87번** |
| 잡은 것 | 3종 중 1종 | 3종 중 1종 |

그때 AI 는 표준편차를 **개수로 나눴습니다**(모표준편차). 값이 작아지니 z 가 커지고,
그래서 더 자주 울립니다. **학생이 배운 「개수−1」이 왜 그런지가 여기서 숫자로 보입니다.**

> **매번 같은 코드가 나오지는 않습니다.** 숫자가 반대로 갈리면 그대로 읽으면 됩니다 —
> 중요한 것은 어느 쪽이 이기느냐가 아니라 **판정할 수 있다는 것**입니다.

**정답을 말하지 마세요.** 「어느 쪽이 낫나, 왜」는 학생이 답해야 오늘의 무기가 됩니다.

## 힌트 카드 — 단톡방에 복붙

붙여넣기 전 매번 **"막혀 있는 게 정상입니다"** 를 먼저 말합니다.

**힌트 1 (시작 15분 뒤 · TODO 1 윈도 통계)**

> 📌 힌트 1 — TODO 1 (윈도 통계)
>
> 막히는 곳은 대부분 "지금 값을 통계에 넣느냐"와 자르는 범위입니다.
>
> · 통계는 지금 값 바로 앞 W개로만 냅니다. 지금 값을 넣으면 튀는 값이 자기 평균을 끌어올려 자신을 숨깁니다
> · values[i-window:i] — 파이썬은 뒤끝(i)을 뺍니다
> · 앞이 모자라면(i < window) None 을 돌려줍니다
> · 표본 표준편차는 (개수−1)로 나눕니다
>
> seg = values[i - window:i]
> mean = sum(seg) / len(seg)
> var = sum((x-mean)**2 for x in seg) / (len(seg)-1)

**힌트 2 (25분 뒤 · TODO 2 임계 판정)**

> 📌 힌트 2 — TODO 2 (임계 판정)
>
> ZeroDivisionError 가 나면 표준편차가 0인 구간입니다.
> 최근 W개가 완전히 똑같았다는 뜻이고, 실제 데이터에서 생깁니다.
>
> 정답이 하나가 아닙니다. 하나를 고르고 이유를 말할 수 있으면 됩니다:
> · False 를 돌려준다 — 판단 불가 구간은 알람을 안 울린다
> · 값이 평균과 다르면 True — 계속 같다가 달라졌으니 이상이다
> · 아주 작은 수를 더해 나눈다 — 편법. 왜 위험한지 설명할 수 있어야 합니다
>
> z = (value - mean) / std
> return abs(z) > k

**힌트 3 (35분 뒤 · TODO 3 결측 처리)**

> 📌 힌트 3 — TODO 3 (결측 처리)
>
> TypeError: unsupported operand … 가 나면 None 을 계산에 넣은 것입니다.
> EQ-01 에 2시간(120개)짜리 빈 구간이 있습니다.
> 값이 없는지 확인은 if v is None: 입니다 (== None 이 아닙니다).
>
> 선택지와 각각의 대가 — 이게 AI 비교의 재료입니다:
> · 그냥 둔다 (그 구간은 판정 안 함) — 결측 자체는 못 잡는다
> · 직전 값으로 메운다 — 2시간 내내 같은 값 → 표준편차 0 → 값이 돌아오는 순간 없던 이상이 생긴다
> · 앞뒤 평균으로 메운다 — 없는 값을 지어낸다. 그 구간 판정은 거짓말이 된다
> · 결측 자체를 이상으로 본다 — 센서 고장을 잡는다. 단, 온도·진동 이상과는 다른 종류
