# 3일차 진행

강사가 보는 것은 **이 문서 하나**와 **리모컨 화면** 둘뿐입니다.

**리모컨** — 크롬에서 `http://34.64.94.16:8000/console`
오른쪽 위 칸에 강사 토큰을 넣고 **연결**. 수업 내내 이 탭을 열어 둡니다.

**오늘 리모컨을 누르는 건 두 번입니다** — 30장에서 제어 개방, 40장에서 고장 주입.

**강사도 학생과 똑같이 실습합니다** — 번호만 `S00` 으로 고정입니다.

```
uv run 내번호.py S00
```

## 아침

**어제 VM 을 껐으면 켭니다.** 약 1분 뒤 서버가 자동으로 뜹니다.

```
gcloud compute instances start knu-factory --zone=asia-northeast3-a
```

그다음 리모컨에서 셋만 봅니다.

1. **연결** 을 누른다 → 「러너 상태」에 초록불
2. 「가상 시계」가 **×60** 인지 (오후에 ×120 으로 올립니다)
3. 「제어 API 개방」이 **잠금**인지 — 오전에는 잠긴 채로 갑니다

> ### ★ 배정은 절대 비우지 마세요
> 「네임스페이스 초기화」나 자리 풀기를 오늘 아침에 누르면
> **39명이 어제 만든 공장을 통째로 잃습니다.** 어제 번호 그대로 갑니다.

공장은 새로 시작하지만 **번호와 학생 코드는 그대로**입니다.
번호를 잊은 학생은 `uv run 내번호.py` 를 다시 치면 같은 번호가 나옵니다.

## ★ 제어 개방 (30장) — 리모컨에서

맨 위 「3일차 준비 — 한 번에」에서

**[3일차 시작 (제어 개방 + 배속 ×120)]** 한 번.

제어 개방과 배속이 같이 걸립니다. **슬라이드를 넘기면서 실제로 누르는 것이 가장 좋습니다** —
학생 화면의 「잠김」이 「개방」으로 바뀌는 것을 보게 됩니다.

**안 누르면 학생 `loop.py` 가 전부 403 으로 죽습니다.**

## ★ 고장 주입 (40장) — 순서가 생명

**전원이 `uv run loop.py` 를 돌린 것을 확인한 뒤에** 넣습니다.

리모컨 「이상 주입 — 직접 지정」에서

| 고를 것 | 값 |
|---|---|
| 대상 | **\* 전체** |
| 종류 | **온도 드리프트** |
| 설비 | (종류별 기본) 그대로 |

**"지금 넣습니다. 1~3분 조용한 것이 정상입니다" 라고 말한 뒤 [주입].**

> ### ★ 먼저 돌리게 하고, 그다음 주입
> 주입은 가상 5시간짜리라 배속 ×120 에서 **실제 150초면 끝납니다.**
> 먼저 주입하고 학생이 나중에 돌리면 이미 끝나 있어 영영 못 봅니다 —
> 화면엔 「감지 이상 없음」만 찍히고 학생은 자기 코드가 틀린 줄 압니다.
>
> **늦게 시작한 학생 한 명은** 대상에서 그 번호만 골라 다시 [주입].

## 못 끝낸 학생

시간이 15분 남았는데 못 돌린 학생 — **실습 가이드(3일차) 의 「시간이 없을 때」** 를 열게 하세요.

단톡방 공지용:

> 📌 폐루프에서 막힌 분 — 실습 가이드 맨 뒤 **「시간이 없을 때」** 를 보세요.
> 세 자리를 다 못 채워도 폐루프는 닫힙니다. `to_commands()` 는 **감속 하나만** 있으면 됩니다.
> 그래도 시간이 없으면 `uv run loop.py --열기 1` (1 감지 · 2 진단 · 3 조치 · 전부).
> 주입 후 2분 침묵은 고장이 아니라 대기입니다.

막힌 자리 하나만 열면 됩니다.

| 어디서 막혔나 | 시킬 명령 |
|---|---|
| 2일차 `detect.py` | `uv run 점검.py --열기 1` (2·3 도 같은 식) |
| 3일차 오전 도구 | `uv run 점검.py --열기 1` |
| 3일차 오후 폐루프 | `uv run loop.py --열기 1` (1 감지 · 2 진단 · 3 조치) |
