## ④ uv 설치하고 한 번 돌려 보기 (5분)

**③에서 연 VS Code 안에서** 합니다. 창을 따로 열 필요 없습니다.

**1. 터미널을 엽니다** — 위 메뉴 **터미널 → 새 터미널** (또는 `Ctrl` + `` ` ``)
창 아래쪽에 검은 칸이 생기고, 거기에 명령을 칩니다.

**2. 아래 한 줄을 붙여넣고 Enter** — 실습에 쓸 `uv` 를 깝니다.

```
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
```

**3. 터미널을 닫고 새로 엽니다** — 방금 깐 것을 인식시키려면 필요합니다.
터미널 패널 오른쪽 **휴지통 아이콘**을 눌러 닫고, 다시 **터미널 → 새 터미널**.

**4. 실습이 돌아가는지 확인합니다** — 아래 두 줄을 붙여넣고 Enter

```
cd 2일차/실습
uv run 점검.py
```

**처음 한 번은 1~2분 걸립니다** — 파이썬과 라이브러리를 이때 갖춥니다.
아래처럼 점검 결과가 뜨면 성공입니다.
(아직 아무것도 안 채웠으니 「[ ]」 표시가 나오는 것이 정상입니다.)

```
==========================================================
내 코드 점검   —   3개 중 0개 통과
==========================================================

  [ ] TODO 1 · window_stats
        아직 안 채웠습니다.
  [ ] TODO 2 · is_anomaly
        아직 안 채웠습니다.
  [ ] TODO 3 · handle_missing
        아직 안 채웠습니다.

  다음에 볼 곳 — TODO 1
```

> **「uv 를 찾을 수 없다」가 나오면** — 잘못하신 것이 아닙니다.
> 새로 깐 프로그램을 창이 아직 못 찾는 것뿐입니다. **VS Code 를 완전히 껐다가
> 다시 켜고** 위 두 줄을 다시 치면 됩니다. (실습 폴더에 그것까지 자동으로 잡아 주는
> 설정을 넣어 두었지만, 폴더를 열기 전에 깐 경우에는 한 번 껐다 켜야 합니다.)
