## ④ uv 설치하고 한 번 돌려 보기 (5분)

**③에서 연 VS Code 안에서** 합니다. 창을 따로 열 필요 없습니다.

**1. 터미널을 엽니다** — 위 메뉴 **터미널 → 새 터미널** (또는 `Ctrl` + `` ` ``)
창 아래쪽에 검은 칸이 생기고, 거기에 명령을 칩니다.

**2. 아래 한 줄을 붙여넣고 Enter** — 실습에 쓸 `uv` 를 깝니다.

```
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
```

**3. 터미널을 닫고 새로 엽니다** — 방금 깐 것을 인식시키려면 필요합니다.
터미널 패널 오른쪽 **휴지통 아이콘**을 눌러 닫고, 다시 **터미널 → 새 터미널**.

**4. 실습이 돌아가는지 확인합니다** — 아래 두 줄을 붙여넣고 Enter

```
cd 2일차/실습
uv run 확인.py
```

**처음 한 번은 1~2분 걸립니다** — 파이썬과 라이브러리를 이때 갖춥니다.
아래처럼 점검 결과가 뜨면 성공입니다.
(아직 아무것도 안 채웠으니 「[ ]」 표시가 나오는 것이 정상입니다.)

```
==============================================================
내 코드 확인   —   3개 중 0개 통과
==============================================================

  [ ] 1 · window_stats  (빈칸 1 · 2)
       아직 안 채웠습니다 — 빈칸의 `...` 를 고칩니다.

  [ ] 2 · is_anomaly  (빈칸 3 · 4)
       아직 안 채웠습니다 — 빈칸의 `...` 를 고칩니다.

  [ ] 3 · handle_missing  (빈칸 5)
       아직 안 채웠습니다 — 빈칸의 `...` 를 고칩니다.

  다음에 볼 곳 — 빈칸 1
```

## ⑤ WSL 켜고 · Docker Desktop 설치하고 · 공장 켜 보기 (20분 + 내려받기 시간)

실습에서 **가상 공장 한 채**가 여러분 컴퓨터 안에서 돕니다. 그 공장을 담는
그릇이 Docker 입니다. **내려받을 것이 커서(수백 MB) 이 단계만은 꼭 전날까지,
집이나 기숙사 와이파이에서** 해 주세요 — 강의장에서 39명이 같이 받으면 그날
실습이 늦어집니다.

**1. 먼저 WSL 을 켭니다** — Docker 가 이 위에서 돕니다. Docker 공식 문서가
WSL 을 먼저 켜라고 안내합니다.

윈도우 검색에서 **PowerShell** 을 찾아 **「관리자 권한으로 실행」** 을 누르고,
아래 한 줄을 붙여넣고 Enter — 끝나면 **컴퓨터를 다시 시작**합니다.

```
wsl --install
```

- 설치 대신 **사용법(도움말) 화면이 잔뜩 나오면** — 이미 켜져 있는 컴퓨터입니다.
  재시작 없이 그대로 다음으로 가면 됩니다.
- 다시 시작한 뒤 **Ubuntu 라는 검은 창**이 열려 사용자 이름을 물을 수 있습니다.
  이 실습은 그 창을 쓰지 않으니 **만들어도 되고, 그냥 닫아도 됩니다.**

**2. Docker Desktop 을 받습니다** — https://www.docker.com/products/docker-desktop
에서 **Download Docker Desktop** 을 누르면 목록이 펼쳐집니다.
**Download for Windows – AMD64** 를 고릅니다.

![내려받기 목록 — Download for Windows – AMD64](그림/docker_1_다운로드.png)

**3. 받은 파일을 실행합니다** — Configuration 화면이 나오면 **아무것도 바꾸지
말고 OK**. 이미 골라져 있는 「Per-user installation (Recommended)」이 화면
설명 그대로 **WSL 2 backend 를 쓰는** 방식입니다 — 1번에서 켠 WSL 위에서
돈다는 뜻입니다.

![Configuration — 그대로 두고 OK](그림/docker_2_설치설정.png)

파일이 풀리는 동안 기다립니다 (몇 분).

![Unpacking files — 기다리면 됩니다](그림/docker_3_설치중.png)

**Installation succeeded** 가 뜨면 **Close** 를 누릅니다.

![Installation succeeded — Close](그림/docker_4_설치완료.png)

**4. Docker Desktop 을 실행합니다** — 바탕화면의 Docker Desktop 아이콘을
엽니다. 먼저 약관 화면 — **Accept**.

![약관 — Accept](그림/docker_5_약관.png)

다음은 로그인(Welcome to Docker) 화면 — 계정은 필요 없습니다.
**오른쪽 위 Skip** 을 누릅니다.

![Welcome to Docker — 오른쪽 위 Skip](그림/docker_6_건너뛰기.png)

**5. WSL2 로 도는지 눈으로 확인합니다** — 위쪽 막대의 **톱니(설정) 아이콘**을
누릅니다.

![위쪽 막대 — 톱니(설정) 아이콘](그림/docker_7_설정버튼.png)

**General** 화면의 「Choose how to run Docker containers」에서
**WSL2 가 골라져 있으면** 그대로 창을 닫습니다. 바꿀 것은 없습니다.

![Settings → General — WSL2 가 골라져 있습니다](그림/docker_8_wsl2확인.png)

창 왼쪽 아래가 **초록색(Engine running)** 이 되면 다음으로 갈 준비가 된 것입니다.

> 실행했을 때 **「WSL update required」** 같은 안내가 나오면 —
> PowerShell 에서 `wsl --update` 한 줄을 치고, 끝나면 Docker Desktop 을
> 껐다 다시 켜세요.
>
> **「virtualization」(가상화) 관련 에러**가 나오면 컴퓨터의 BIOS 설정에서
> 가상화를 켜야 하는 경우입니다 — 어려우면 무리하지 말고 그대로 오세요.
> 아래 「설치가 안 되는 컴퓨터라면」과 같이 진행하면 됩니다.

**6. 공장을 켭니다** — ③에서 연 VS Code 터미널에서 아래 두 줄.

```
cd 공장
docker compose up -d
```

**처음 한 번은 5~10분 걸립니다** — 공장 부품을 이때 다 내려받습니다.
글자가 한참 지나간 뒤 조용해지면 켜진 것입니다.

**7. 공장을 눈으로 봅니다** — 크롬 주소창에 아래를 붙여넣습니다.

```주소
http://localhost:8000
```

초록 네모 여섯 개가 있는 공장 화면이 뜨면 **준비 완료**입니다.

> 공장은 꺼도 됩니다 — 컴퓨터를 끄면 같이 멈추고, 수업 날
> `docker compose up -d` 한 줄이면 다시 켜집니다.
>
> **설치가 안 되는 컴퓨터라면** (회사 노트북 등 관리자 권한이 없는 경우) —
> 그대로 오시면 됩니다. 코딩 실습은 Docker 없이도 전부 할 수 있게
> 준비돼 있고, 공장 화면만 옆자리와 같이 보면 됩니다.

### 잘 안 되면 — 「환경 점검」을 먼저 돌리세요

**잘못하신 것이 아닙니다.** 무엇이 어긋났는지부터 봅니다. 칠 것은 없습니다.

위 메뉴 **터미널 → 작업 실행** → **환경 점검** 을 고르면 세 줄이 나옵니다.

```
C:\Users\...\k-precision-lab                     ← 지금 있는 폴더
C:\Users\...\.local\bin\uv.exe                   ← uv 가 있는 자리
uv 0.11.21 ...                                   ← uv 버전
```

**위에서부터 읽습니다.**

| 이렇게 나오면 | 무엇이 어긋났나 | 하실 일 |
|---|---|---|
| 첫 줄이 `k-precision-lab` 이 아니다 | 다른 곳에서 터미널을 켰습니다 | **파일 → 폴더 열기**로 `k-precision-lab` **폴더를** 여세요 (파일 하나만 열면 안 됩니다) |
| 둘째 줄에 「찾을 수 없습니다」 | 창이 uv 자리를 아직 모릅니다 | **VS Code 를 완전히 껐다가 다시 켜세요** |
| 세 줄이 다 나온다 | 환경은 정상입니다 | 명령을 오타 없이 다시 쳐 보세요 |
