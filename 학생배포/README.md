## 학생은 무엇을 받나

**학생이 받는 것은 이 저장소가 아닙니다.** 여기서 뽑아낸 **실습 저장소**입니다.

```bash
cd 강사용
python 배포본만들기.py --검증
```

`1일차` `2일차` `데이터` 세 폴더가 든 저장소가 나옵니다 — 강의자료 PNG 와 강사 문서는 빠집니다.
학생은 그것을 **`git clone` 으로 받아서 고치기만** 합니다. **올리는 단계가 없습니다.**
그래서 개인 저장소를 만들 필요가 없습니다. 제출은 노션 링크입니다.
