# K-정밀 실습 저장소

경남대 RISE 피지컬AI 사관학교 · 8월 Agentic AI 특강

이틀 동안 여러분은 **가상 공장의 이상을 잡는 코드를 직접 짜고,
그 코드를 AI 의 도구로 내놓아 설비를 실제로 움직이게** 합니다.

---

## 어디부터 여나

| 언제 | 읽을 것 | 열 폴더 |
|---|---|---|
| **1일차** | [`1일차/실습가이드.md`](1일차/실습가이드.md) | `1일차/실습` |
| **2일차** | [`2일차/실습가이드.md`](2일차/실습가이드.md) | `2일차/실습` |

**실습가이드를 VS Code 에 열어 두고 따라오면 됩니다.** 그 문서 하나로 끝까지 갑니다.

> 1일차 1교시는 노션입니다. 앞으로 배울 것을 쌓을 학습 노트를 그 시간에 만듭니다.
> 이 폴더는 **2교시부터** 엽니다.

---

## 폴더 안에 무엇이 있나

```
1일차/
  실습가이드.md      ← 오늘 볼 문서
  실습/
    detect.py       ★ 여기만 고칩니다
    run.py            내 구현을 데이터에 돌리고 채점
    점검.py           막혔을 때 여는 것
    내번호.py         내 공장 받기 (처음 한 번)
    정답/             시간이 다 됐을 때 점검.py --열기 가 읽는 것

2일차/
  실습가이드.md
  실습/
    도구만들기/       오전 — 내 코드를 AI 의 도구로
    폐루프/           오후 — 감지·진단·조치

데이터/              7일치 센서 CSV (실습이 읽어 감)
```

---

## 막히면

**혼자 20분 붙잡고 있는 것이 제일 손해입니다.**

1. `python 점검.py` — 지금 어디까지 됐는지 짚어 줍니다
2. `python 점검.py --힌트 1` → 그래도 모르면 `--힌트 2`
3. 실습가이드 맨 뒤 **「오늘 막힐 수 있는 곳 전부」** 표
4. 그래도 안 되면 **손을 드세요**

**앞에 나와서 발표하는 일은 이틀 내내 없습니다.**
