# 백스테이지 — 강의 전에만 여는 곳

**강의하는 날에는 안 엽니다.** 당일 쓰는 것은 `당일/` 에 있습니다.

| 무엇 | 언제 |
|---|---|
| **`리허설.py`** | D-3 · D-7 — 이틀을 사람 없이 재생 (73항목·약 11분) |
| **`배포본만들기.py`** | 학생 저장소를 뽑는다. **손으로 만들지 말 것** |
| `시뮬레이터/` | 가상 공장 서버. 당일엔 `당일/시작.bat` 이 이걸 띄운다 |
| `센서데이터/` | 7일치 CSV 와 그것을 만든 생성기·검증기 |

## 자주 쓰는 것

```bash
python 리허설.py --token <강사토큰> --부하     # 전 항목. --부하 는 실제 모델 호출(비용)
python 배포본만들기.py --검증                  # 뽑고 학생 조건(cp949)에서 실제로 돌려 확인

cd 시뮬레이터
python tools/selftest_engine.py               # 엔진만 (DB 불필요, 53항목)
python tools/자리배정.py                       # 누가 몇 번을 가져갔나
python 센서데이터/verify.py                    # 7일치 데이터가 강의 서사와 맞는가
```

`시작.bat` 원본은 **`시뮬레이터/시작.bat` 하나뿐**입니다.
`당일/시작.bat` 은 그것을 부르기만 합니다 — 고칠 일이 있으면 여기만 고치세요.
