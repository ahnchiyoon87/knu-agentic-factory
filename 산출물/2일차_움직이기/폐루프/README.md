| 파일 | 함수 | 무엇을 정하는가 |

## 감지 — 어제 것을 그대로 쓰면 안 잡힙니다

1일차 의 이동창 z-score 는 **창 안에서 튀는 값**을 찾습니다.
드리프트는 창까지 같이 올라가서, 창 기준으로는 언제나 평범합니다.

같은 데이터를 두 방식으로 재 본 실측입니다.

| | 드리프트 있음 | 드리프트 없음 |
|---|---|---|
| 어제의 z-score (k=3) | 2건 | 2건 |
| 오늘의 기준 (창 밖 비교) | **+1.06℃ 검출** | 미검출 |

z-score 는 드리프트가 있으나 없으나 같은 수를 냅니다 — **구분하지 못한다**는 뜻입니다.
그래서 오늘은 창 안이 아니라 **창 밖과 비교**합니다.

**단, 창을 잘라야 합니다.** 루프를 오래 돌리면 창이 계속 길어지는데 드리프트는 그 안의
짧은 구간일 뿐이라, 자르지 않으면 12분쯤부터 차이가 +0.50℃ 로 주저앉아 **미탐이 됩니다.**
`config.json` 의 `detect.window_samples` 가 그 상한입니다.

> **시뮬레이터는 배속 ×60 으로 켜져 있습니다** — 공장 4시간이 실제 4분입니다.
> 데이터는 1초에 한 줄씩 들어오고, 그 한 줄이 공장 1분치입니다(부록 A CSV 와 같은 격자).
> 배속이 1이면 드리프트가 실제로 4시간 걸려 안 잡힙니다 — `loop.py --check` 가 경고합니다.

## 승인 관문 — 이건 우리가 정하는 게 아닙니다

교안 10~11장이 못 박은 규칙입니다.

| 명령 | | 왜 |
|---|---|---|
| `set_equipment_speed` | **자동** | rpm 을 되돌리면 그만입니다 |
| `ack_alarm` | **자동** | 되돌릴 수 있습니다 |
| `stop_equipment` | **사람 승인** | 라인이 섭니다 |
| `dispatch_robot` | **사람 승인** | 로봇이 이미 움직입니다 |

갈림은 **되돌릴 수 있는가**입니다. `hitl.py` 가 강제하므로 조치 에이전트에서 우회할 수 없습니다.
바꾸려면 `config.json` 의 `hitl` 만 고칩니다.

```
──────────────────────────────────────────────────────────────
  승인 요청 — 되돌릴 수 없는 행동입니다
    명령   dispatch_robot(AMR-01)
    내용   AMR-01 → EQ-03 로 이동
    이유   미완 정비 작업지시가 원인일 수 있어 현장 확인이 필요합니다.
──────────────────────────────────────────────────────────────
  승인하시겠습니까? [y/N]
```

## 진단 에이전트 — 실제 모델이 진단합니다

`gpt-5.4-mini` 를 **추론 없이** 씁니다. 키는 `.env` 에 한 줄이면 됩니다 — 이 폴더부터
위로 올라가며 처음 만나는 `.env` 를 읽으므로 터미널마다 `export` 하지 않아도 됩니다.

```
OPENAI_API_KEY=sk-proj-...
```

**추론을 끈 이유** — 실측입니다. 진단은 준 자료를 읽고 정리하는 일이라 긴 추론이 도움이 안 됩니다.

| | 실행 가능한 조치를 낸 비율 | 응답 |
|---|---|---|
| `gpt-5.4-mini` · 추론 끔 | **5/5** | 2.9초 · 344토큰 |
| `gpt-5.4-mini` · 추론 low | 4/5 | 4.1초 · 529토큰 |
| `gpt-4.1` | 4/5 | 2.7초 · 217토큰 |

| `config.json` `diagnose.backend` | |
|---|---|
| `openai` (기본) | `openai_model` 로 진단 |
| `rules` | 항상 규칙 기반 |
| `claude` | Anthropic 키를 쓸 때 (코드는 있으나 실행 검증 안 됨) |

> 호출이 실패하면 **규칙 기반으로 자동 대체**됩니다. 키 하나 때문에 데모가 멈추지 않게 하는 장치입니다.
> 어느 쪽이든 결과의 모양은 같아서 조치 에이전트는 차이를 모릅니다.
>
> `.env` 는 저장소에 올리지 마십시오.

> 규칙 기반은 안전망이지 목표가 아닙니다. `build_prompt()` 는 어느 쪽이든 항상 불립니다.
> 우리가 쓴 지시문이 `실행기록.jsonl` 에 남습니다.
