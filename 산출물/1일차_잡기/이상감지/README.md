`[~ ]` 는 **울리긴 했는데 정상 구간에서 울리는 빈도와 다를 게 없다**는 뜻입니다.
이상 구간에서 몇 번 울렸다고 "잡았다"고 하면 안 됩니다. 아무 데서나 그만큼 울리고 있으니까요.

## 미리 말해 두는 것

**온도 드리프트는 아마 안 잡힐 겁니다.** 그리고 그게 맞습니다.

임계값을 낮춰도 안 잡힙니다. 참고 구현으로 재 본 결과입니다.

| 임계 | 아닌데 울린 횟수 | 드리프트 |
|---|---|---|
| k=4.0 | 40회 | 0 / 241 |
| k=3.0 | 566회 | 5 / 241 |
| k=2.0 | **6,374회** | 33 / 241 |

k 를 2까지 낮추면 오탐이 **11배**로 늘지만 드리프트는 여전히 노이즈에 묻힙니다.

왜 그런지가 오늘의 핵심입니다. 한 시간에 0.5도씩 오르는 변화는 **이동평균이 같이 따라 올라가기 때문에** 지금 값과 최근 평균의 차이가 벌어지지 않습니다. 기준선 자체가 함께 움직이는 것입니다.

새벽 3시의 EQ-03 이 그랬습니다. 고정 임계값 80℃ 로도 못 잡았고, 이동 윈도 z-score 로도 못 잡습니다.
