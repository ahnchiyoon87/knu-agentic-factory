# [사전 안내] 경남대 RISE 피지컬AI 사관학교 — 8월 AI 특강 준비 안내

안녕하세요. 특강에서 여러분은 **AI에게 말로 시켜서, 가상 공장을 감시하고 움직이는
시스템을 4일 만에 직접 만들게 됩니다.** 첫날 수업이 바로 실습으로 시작되므로,
아래 준비를 **특강 전날까지** 꼭 마쳐 주세요. 15~20분이면 됩니다.

> 준비가 안 된 채 오시면 첫날 첫 시간을 설치로 보내게 되어 실습 진도를 놓칩니다.
> 막히는 부분은 그대로 두고 오셔도 됩니다 — 첫날 셋업 시간에 도와드립니다.
> 단, **아래 ①~⑤를 시도는 해 보고 오는 것**이 중요합니다.

---

## 준비물

- 노트북 (Windows 10/11 또는 macOS) — **관리자 권한으로 프로그램 설치가 가능해야 합니다**
- 크롬(Chrome) 브라우저
- 전원 어댑터 (4시간 연속 사용)

## ① Python 설치 (3분)

1. https://www.python.org/downloads/ 에서 **Python 3.12** 다운로드 후 실행
2. 설치 첫 화면에서 **"Add python.exe to PATH" 체크박스를 반드시 체크** 후 Install
3. 확인: 명령 프롬프트(cmd)를 열고 `python --version` 입력 → `Python 3.12.x` 가 나오면 성공

## ② Git 설치 (3분)

1. https://git-scm.com/downloads 에서 다운로드 후 실행 (설정은 전부 기본값으로 Next)
2. 확인: 명령 프롬프트에서 `git --version` 입력 → 버전이 나오면 성공

## ③ GitHub 계정 (5분)

1. https://github.com 에서 **Sign up** — 개인 이메일로 가입
2. 아이디는 특강 후에도 **포트폴리오 주소**가 되니 신중히 정하세요 (예: hong-gildong)
3. 확인: 로그인해서 내 프로필 페이지가 열리면 성공
4. **가입한 아이디를 기억해 오세요** — 첫날 실습 저장소를 만들 때 씁니다

## ④ VS Code 설치 (3분)

1. https://code.visualstudio.com 에서 다운로드 후 설치 (기본값으로)
2. 확인: 실행해서 창이 열리면 성공

## ⑤ VS Code에 Claude(AI 코딩 도우미) 설치 (5분)

1. VS Code 왼쪽의 블록 모양 아이콘(Extensions) 클릭
2. 검색창에 `Claude Code` 입력 → 설치(Install)
3. 왼쪽에 생긴 Claude 아이콘 클릭 → 안내에 따라 **로그인**
   - 계정 안내: `[■ 계정 발급 방식 — 확정 후 기입: 개인 가입 or 배부 계정]`
4. 확인: 채팅창에 `안녕` 이라고 쳐서 답이 오면 성공
