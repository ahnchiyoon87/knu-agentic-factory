# 경남대 8월 특강 — 여기가 입구입니다

최상위는 둘입니다. **「하는 것」과 「만드는 것」.**

| 폴더 | 무엇 |
|---|---|
| **`강의/`** | 특강을 **하는** 전부 — 일차별(2일차·3일차) 진행 문서·슬라이드·실습 원본 + 서버 + 제출물 |
| **`제작/`** | 특강을 **만드는** 전부 — 슬라이드 소스 · 검증·빌드 도구 · 산출물 |

`강의/` 안은 **일차별**입니다. 각 일차 폴더에 강사 문서(`진행.md`) 하나,
슬라이드(`강의자료/`), 학생 실습 원본(`실습/`)이 있습니다.
학생이 읽는 문서는 `강의/` 바로 아래 있습니다 — `준비안내.md` 와 **일차별 실습 가이드 두 권**.

## 오늘 뭘 하려고 오셨나요

| 하려는 일 | 여기부터 |
|---|---|
| **강의하는 날이다** | 그날의 `강의/2일차/진행.md` 또는 `강의/3일차/진행.md` **하나만** |
| 서버를 켜야 한다 | `gcloud compute instances start knu-factory --zone=asia-northeast3-a` |
| 학생 자료를 뽑아야 한다 | `uv run 제작/검증도구/배포본만들기.py --검증` |
| 드라이브에 올릴 것 | `uv run 제작/빌드도구/드라이브폴더만들기.py` → `제작/산출물/드라이브업로드.zip` |
| 슬라이드를 고쳐야 한다 | `제작/덱빌드/build_*.py` → `레이아웃검사.py` → `render.py` → `제작/빌드도구/pptx만들기.py` |
| 가이드에 넣을 화면을 찍어야 한다 | `강의/촬영목록.md` |
| 수업 전 전체 점검 | `uv run 제작/검증도구/리허설.py --token <토큰> --부하` (74항목 · 약 11분 · **비용 발생**) |
| **이어받는 사람이다** | `핸드오프.md` |

**서버는 클라우드 `http://34.64.94.16:8000` 하나뿐입니다.** 강의장 와이파이가 기기 간 통신을
막아 학생이 강사 PC 에 붙을 수 없습니다 — **강사 PC 에서 서버를 띄우지 않습니다.**

## 손으로 만들지 않는 것

`제작/산출물/` 안의 것, 슬라이드 PNG·pptx, 실습 ZIP, 학생 PDF 는 **전부 스크립트가 뽑습니다.**
고치려면 **원본**을 고치고 다시 뽑으세요.

| 산출물 | 원본 |
|---|---|
| 슬라이드 PNG · pptx | `제작/덱빌드/build_*.py` |
| 학생 실습 파일 · ZIP | `강의/2일차/실습/` · `강의/3일차/실습/` |
| 학생 가이드 PDF | `강의/실습가이드_2일차.md` · `강의/실습가이드_3일차.md` |
| 제출용 강의안 docx | `강의/강의안/*.md` |

## 일차 표기

전체 4일 과정 기준 — 우리 이틀은 **2일차·3일차**이고, **저장소 전체가 이 번호로 통일**돼 있습니다.

## 절대 규칙

- 개인 단위입니다. 팀·발표·투표가 없습니다 (시연은 강사만 — 학생을 앞에 세우지 않습니다)
- **39명 전원이 같은 장면을 봅니다**
- **반전은 학생이 발견합니다** — 어떤 이상이 잡히고 안 잡히는지 강의자료에도 가이드에도 쓰지 않습니다
- **화면은 실제 캡처만 씁니다.** 그려서 흉내 내지 않습니다
- AI 키는 학생에게 주지 않습니다. 서버가 쥐고 중계합니다
- **`.env` 는 커밋하지 않습니다**
