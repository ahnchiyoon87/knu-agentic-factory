# 경남대 RISE 피지컬AI 사관학교 — 8월 특강 (1일차 · 2일차)

> **이 문서 하나로 전체를 파악할 수 있게 썼습니다.** 위에서 아래로 읽으면 됩니다 (5분).

---

## 1. 무엇을 하는가

경남대 컴퓨터공학과 **1~4학년 39명**에게 이틀(하루 4시간)을 강의합니다.
학생이 배우는 것을 한 문장으로 — **"AI가 공장의 이상을 알아채고 스스로 조치하게 만드는 법"**.

| | 제목 | 학생이 하는 일 |
|---|---|---|
| **1일차** | **잡기** | 이상을 찾아내는 알고리즘을 **직접 짜고**, 그것이 어디까지 되는지 확인한다 |
| **2일차** | **움직이기** | 내 코드를 AI 의 도구로 내놓고, AI 가 판단해 **설비를 실제로 움직이게** 한다 |

마지막 장면이 이 특강의 존재 이유입니다 — 학생이 만든 AI 가 고장을 스스로 알아채고,
원인을 찾고, 기계를 늦추고, **사람 승인을 받아 로봇을 출동시킵니다.**

목적은 지식 전달이 아니라 **9월 본과정 이탈 방지**입니다.
"얼마나 가르쳤나"가 아니라 **"끝까지 남았나"** 로 성패가 갈립니다.

> 이 이틀 앞뒤로 대표님 세션과 PLC 강사 세션이 붙습니다. **이 저장소는 그 이틀을 다루지 않습니다.**

## 2. 절대 규칙 — 어기면 수업이 무너집니다

| # | 규칙 |
|---|---|
| 1 | **개인 단위.** 팀·PBL 없음. `S01`~`S39` 각자 자기 공장 |
| 2 | **발표·시연·투표·시상 없음.** 대신 "다 같이 엔터" — 39개 화면에서 동시에 |
| 3 | **39명 전원이 같은 장면을 본다.** 창의성으로 갈리는 구간을 만들지 않는다 |
| 4 | **이탈 절대 방지.** 막힌 학생도 다음 단계로 갈 수 있어야 한다 |
| 5 | **반전은 학생이 발견한다.** 어떤 이상이 잡히고 안 잡히는지 강의자료에 한 글자도 쓰지 않는다 |
| 6 | **AI 없이 조용히 넘어가지 않는다.** 진단이 안 되면 학생이 알 수 있게 한다 |
| 7 | **키는 학생에게 주지 않는다.** 서버가 쥐고 중계한다 |
| 8 | **대본이 없다.** 슬라이드만 보고 뜻이 통해야 한다 |
| 9 | **무대는 K-정밀 하나.** 여기 없는 숫자를 지어내지 않는다 |

**PNG 를 직접 고치지 마세요.** 빌드 스크립트가 원본입니다.

```bash
cd 작업장/강의자료
python build_1일차.py      # 덱 HTML 생성
```
