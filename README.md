
## 강의 전에 — 백스테이지에서

```bash
cd 백스테이지

python 리허설.py --token <강사토큰> --부하     # 이틀을 사람 없이 재생 (73항목·약 11분)
python 배포본만들기.py --검증                  # 학생 저장소를 뽑고 학생 조건에서 확인 (24항목)
```

**학생 저장소를 손으로 만들지 마세요.** `배포본만들기.py` 가 `학생배포/` 를 그대로 뽑습니다.
한 번 손으로 만들었다가 이쪽 구조가 바뀌었는데 저쪽이 안 따라와 통째로 어긋난 적이 있습니다.
