# 경남대 8월 특강 — 여기가 입구입니다

최상위는 둘입니다. **「하는 것」과 「만드는 것」.**

| 폴더 | 무엇 |
|---|---|
| **`특강/`** | 특강을 **하는** 전부 — 일차별(2일차·3일차) 진행 문서·슬라이드·실습 원본 + 서버 + 제출물 |
| **`제작/`** | 특강을 **만드는** 전부 — 슬라이드 소스 · 강의안 원본 · 검증·빌드 도구 · 산출물 · 기록 |

`특강/` 안은 **일차별**입니다. 각 일차 폴더에 강사 문서(`진행.md`) 하나,
슬라이드(`이론/`), 학생에게 나가는 원본(`실습가이드.md`·`실습/`)이 같이 있습니다.

## 오늘 뭘 하려고 오셨나요

| 하려는 일 | 여기부터 |
|---|---|
| **강의하는 날이다** | 그날의 `특강/2일차/진행.md` 또는 `특강/3일차/진행.md` **하나만** |
| 처음 왔다 | `특강/README.md` — 언제 무엇을 여는지 한 장 |
| 서버를 켜야 한다 | `특강/시뮬레이터/시작.bat` 더블클릭 |
| 학생 자료를 뽑아야 한다 | `python 제작/검증도구/배포본만들기.py --검증` |
| 드라이브에 올릴 것 | `python 제작/빌드도구/드라이브폴더만들기.py` → `제작/산출물/드라이브업로드.zip` |
| 슬라이드를 고쳐야 한다 | `제작/덱빌드/build_*.py` → `render.py` → `제작/빌드도구/pptx만들기.py` |
| 대표님께 보낼 것 | `python 제작/빌드도구/공유본만들기.py` |
| 수업 전 전체 점검 | `python 제작/검증도구/리허설.py --token <토큰> --부하` (75항목 · 약 11분) |
| **이어받는 사람이다** | `제작/기록/핸드오프.md` |

## 손으로 만들지 않는 것

`제작/산출물/` 안의 것, 슬라이드 PNG·pptx, 실습 ZIP 은 **전부 스크립트가 뽑습니다.**
고치려면 **원본**을 고치고 다시 뽑으세요.

| 산출물 | 원본 |
|---|---|
| 슬라이드 PNG · pptx | `제작/덱빌드/build_*.py` |
| 학생 실습 파일 · ZIP | `특강/2일차/`·`특강/3일차/` 의 실습가이드·`실습/` |
| 제출용 강의안 docx | `제작/강의안원본/*.md` |

## 일차 표기

전체 4일 과정 기준 — 우리 이틀은 **2일차·3일차**이고, **저장소 전체가 이 번호로 통일**돼 있습니다.

## 절대 규칙

- 개인 단위입니다. 팀·발표·투표가 없습니다 (시연은 강사만 — 학생을 앞에 세우지 않습니다)
- **39명 전원이 같은 장면을 봅니다**
- **반전은 학생이 발견합니다** — 어떤 이상이 잡히고 안 잡히는지 강의자료에 쓰지 않습니다
- AI 키는 학생에게 주지 않습니다. 서버가 쥐고 중계합니다
- **`.env` 는 커밋하지 않습니다**
