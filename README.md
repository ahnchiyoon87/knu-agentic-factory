## 협업 규칙

1. **`.env` 는 커밋 금지** — `.gitignore` 가 막고 있지만, 새 자격증명 파일을 만들 때도 같은 원칙
2. 산출물 코드를 고치면 **그 폴더의 `verify_lab.py` 를 돌려서 통과를 확인**하고 커밋
3. 교안 사양(수치·순서·이름)은 임의 변경 금지 — 다르게 하고 싶으면 회의 문서에 별도 항목으로 보고
4. 큰 파일(pptx·zip·영상)은 커밋하지 않음 — `.gitignore` 가 확장자로 막고 있음. 필요하면 별도 공유
