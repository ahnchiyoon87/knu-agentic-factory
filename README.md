# 경남대 8월 특강 — 여기가 입구입니다

최상위는 둘입니다. **「하는 것」과 「만드는 것」.**

| 폴더 | 무엇 |
|---|---|
| **`특강/`** | 특강을 **하는** 데 쓰는 전부 — 당일 자료 · 학생 배포 원본 · 서버 · 제출물 |
| **`제작/`** | 특강을 **만드는** 전부 — 슬라이드 소스 · 강의안 원본 · 검증·빌드 도구 · 산출물 |

`특강/` 안은 다시 **「누가 보는가」로** 나눠져 있습니다.
그래야 학생에게 뽑아 줄 때 **강사 것과 정답이 딸려 나가지 않습니다.**

| 폴더 | 누가 보나 | 무엇이 들었나 |
|---|---|---|
| **`특강/학생배포/`** | **학생** | 학생에게 통째로 나가는 실습 파일. 여기 있는 것만 학생이 봅니다 |
| **`특강/당일/`** | **강사 (강의장)** | 강의하는 날 여는 것 — 진행표 · 슬라이드 · 안내문 · 서버운영 |
| **`특강/시뮬레이터/`** | **강사 (서버)** | 가상 공장 서버. 당일에도 이걸 돌립니다 (`시작.bat` · 제어개방 · 자리배정) |
| **`특강/강의안/`** | **발주처** | 제출용 docx 2개 |
| **`제작/`** | **만드는 사람** | 덱빌드 · 강의안원본 · 참고자료 · 검증도구 · 빌드도구 |
| **`제작/산출물/`** | — | **스크립트가 뽑은 것.** 지워도 됩니다. 손으로 고치지 마세요 |

---

## 오늘 뭘 하려고 오셨나요

| 하려는 일 | 여기부터 |
|---|---|
| **강의하는 날이다** | `특강/당일/진행표.md` **하나만** 보면 됩니다 |
| 서버를 켜야 한다 | `특강/시뮬레이터` 에서 `python -m server.run` (또는 `시작.bat`) |
| 학생 자료를 뽑아야 한다 | `python 제작/검증도구/배포본만들기.py --검증` |
| 드라이브에 올릴 것을 만든다 | `python 제작/빌드도구/드라이브폴더만들기.py` |
| 슬라이드를 고쳐야 한다 | `제작/덱빌드/build_*.py` → `render.py` → `제작/빌드도구/pptx만들기.py` |
| 대표님께 보낼 것 | `python 제작/빌드도구/공유본만들기.py` |
| 수업 전 전체 점검 | `python 제작/검증도구/리허설.py --token <토큰> --부하` (75항목 · 11분) |
| **이어받는 사람이다** | `핸드오프.md` — 지금 상태와 남은 일이 다 있습니다 |

## 손으로 만들지 않는 것

`제작/산출물/` 안의 것, 슬라이드 PNG·pptx, 실습 ZIP 은 **전부 스크립트가 뽑습니다.**
손으로 고치면 다음에 뽑을 때 사라집니다. 고치려면 **원본**을 고치고 다시 뽑으세요.

| 산출물 | 원본 |
|---|---|
| 슬라이드 PNG · pptx | `제작/덱빌드/build_*.py` |
| 학생 실습 파일 · ZIP | `특강/학생배포/` |
| 제출용 강의안 docx | `제작/강의안원본/*.md` |

## 일차 표기 — 헷갈리기 쉽습니다

**저장소 안은 전부 `1일차`·`2일차`** 입니다 (저희가 맡은 이틀 기준).
**`특강/강의안/` 의 docx 만 2일차·3일차** 입니다 — 전체 4일 과정 기준이라 받는 쪽이 그렇게 부릅니다.

## 절대 규칙

- 개인 단위입니다. 팀·발표·투표가 없습니다 (시연은 강사만 합니다 — 학생을 앞에 세우지 않습니다)
- **39명 전원이 같은 장면을 봅니다**
- **반전은 학생이 발견합니다** — 어떤 이상이 잡히고 안 잡히는지 강의자료에 쓰지 않습니다
- AI 키는 학생에게 주지 않습니다. 서버가 쥐고 중계합니다
- **`.env` 는 커밋하지 않습니다**
