## 협업 규칙

1. **`.env` 는 커밋 금지** — `.gitignore` 가 막고 있지만, 새 자격증명 파일도 같은 원칙
2. 산출물 코드를 고치면 **그 폴더의 `verify_lab.py` 를 돌려 통과 확인** 후 커밋
3. 교안 사양(수치·순서·이름)은 임의 변경 금지 — 다르게 하려면 회의에서 합의 후
4. 큰 파일(pptx·zip·영상)은 커밋하지 않음 — `.gitignore` 가 확장자로 막음. 필요하면 별도 공유
5. 학생 재료를 고치면 **k-precision-lab 에도 반영** (원본은 이 저장소, 배포본이 학생 레포)
