# 경남대 8월 특강 — 여기가 입구입니다

폴더는 **「누가 보는가」로** 나눠져 있습니다. 무엇인지가 아니라.
그래야 학생에게 뽑아 줄 때 **강사 것과 정답이 딸려 나가지 않습니다.**

| 폴더 | 누가 보나 | 무엇이 들었나 |
|---|---|---|
| **`학생배포/`** | **학생** | 학생에게 통째로 나가는 실습 파일. 여기 있는 것만 학생이 봅니다 |
| **`당일/`** | **강사 (강의장)** | 강의하는 날 여는 것 — 진행표 · 슬라이드 · 인쇄물 · 서버운영 |
| **`백스테이지/`** | **강사 (강의 전)** | 서버 · 리허설 · 배포본 뽑기 · 센서 데이터. 당일엔 안 엽니다 |
| **`제작/`** | **만드는 사람** | 슬라이드 소스 코드 · 강의안 원본 · 참고자료 |
| **`강의안/`** | **발주처** | 제출용 docx |
| **`산출물/`** | — | **스크립트가 뽑은 것.** 지워도 됩니다. 손으로 고치지 마세요 |

---

## 오늘 뭘 하려고 오셨나요

| 하려는 일 | 여기부터 |
|---|---|
| **강의하는 날이다** | `당일/진행표.md` **하나만** 보면 됩니다 |
| 서버를 켜야 한다 | `백스테이지/시뮬레이터` 에서 `python -m server.run` |
| 학생 자료를 뽑아야 한다 | `python 백스테이지/배포본만들기.py --검증` |
| 드라이브에 올릴 것을 만든다 | `python 백스테이지/드라이브폴더만들기.py` |
| 슬라이드를 고쳐야 한다 | `제작/덱빌드/build_*.py` → `render.py` → `백스테이지/pptx만들기.py` |
| 대표님께 보낼 것 | `python 백스테이지/공유본만들기.py` |
| 수업 전 전체 점검 | `python 백스테이지/리허설.py --token <토큰> --부하` (75항목 · 11분) |
| **이어받는 사람이다** | `핸드오프.md` — 지금 상태와 남은 일이 다 있습니다 |

---

## 손으로 만들지 않는 것

`산출물/` 안의 것, 슬라이드 PNG·pptx, 실습 ZIP 은 **전부 스크립트가 뽑습니다.**
손으로 고치면 다음에 뽑을 때 사라집니다. 고치려면 **원본**을 고치고 다시 뽑으세요.

| 산출물 | 원본 |
|---|---|
| 슬라이드 PNG · pptx | `제작/덱빌드/build_*.py` |
| 학생 실습 파일 · ZIP | `학생배포/` |
| 제출용 강의안 docx | `제작/강의안원본/*.md` |

---

## 일차 표기 — 헷갈리기 쉽습니다

**저장소 안은 전부 `1일차`·`2일차`** 입니다 (저희가 맡은 이틀 기준).
**`강의안/` 의 docx 만 2일차·3일차** 입니다 — 전체 4일 과정 기준이라 받는 쪽이 그렇게 부릅니다.

## 절대 규칙

- 개인 단위입니다. 팀·발표·시연·투표가 없습니다
- **39명 전원이 같은 장면을 봅니다**
- **반전은 학생이 발견합니다** — 어떤 이상이 잡히고 안 잡히는지 강의자료에 쓰지 않습니다
- AI 키는 학생에게 주지 않습니다. 서버가 쥐고 중계합니다
- **`.env` 는 커밋하지 않습니다**
